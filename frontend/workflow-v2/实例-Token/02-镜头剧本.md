# 02 · 镜头剧本（段级）

> 出图之前写，写完由用户审一次（门 2）。没审过不许批量出图。
> 一段一份，不是一镜一份；镜在段内可以多条。

## 模板

```markdown
## <段号> · <段名>（句 a–b / 镜 x–y / 时长）

### ① 声音给了什么
<逐句列出信息点，不写画面>

### ② 画面要新增什么
<这段结束时观众多知道了什么；不能是"把配音换成大字">

### ③ 主对象怎么变
<起 → 中 → 止；每步是同一个对象的状态变化，不是换对象>

### ④ 镜头怎么带人看
<固定 / 推 / 拉 / 焦点交接；什么时候动，动多少>

### ⑤ 高潮与停顿
<高潮落在第几句；停顿多久；为什么停在这里>

### ⑥ 对标
<哪条片的哪一段；借什么（节奏/构图/转场），不借什么>

### ⑦ 边界
<不许出现的元素；与上一段/下一段的接点>
```

---

## 实例：D02 · 看不见（句 7–11 / 镜 9–16 / 50.91s）

### ① 声音给了什么
- 句 7：石油有价格，token 也有
- 句 8：你天天用 AI，付过钱吗
- 句 9：打开应用 → 输入框 → 打字 → 回答 → 你见过 token 吗 → 没有 → 只看到字在蹦
- 句 10：账在哪？被藏起来了
- 句 11：大部分办公 AI 免费，免费就不给你看账单

### ② 画面要新增什么
把"看不见"变成可看：**扫描光穿过界面**、**字在蹦但底下空着**、**账单被纸盖住**。
不是把"没有"写成大字。

### ③ 主对象怎么变
界面（在场）→ 扫描光（寻找）→ 空槽（暴露）→ 账单（出现）→ 纸（盖住）

### ④ 镜头怎么带人看
固定机位为主；句 9 说到"底下"时视线下移一次，不推不摇；句 10 切到账单时用硬切。

### ⑤ 高潮与停顿
高潮在句 9 的"没有"——用一个 **0.4s 黑场**，之后字继续蹦但底部空槽可见。
停顿：句 10"被藏起来了"之后 0.5s，让纸落稳。

### ⑥ 对标
借某条已确认片子的"扫描光找东西"节奏（快扫、慢停），不借它的构图和配色。

### ⑦ 边界
- 不出现真实品牌 UI 的商标；
- 不用红色警示（本段情绪是"疑惑"，不是"危险"）；
- 接点：上一段末帧是"石油/价格"意象，本段首帧必须是"token 也有价格"，不能直接跳界面。
