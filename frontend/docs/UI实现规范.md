## 一、视觉方向

**目标形态**：专业暗色桌面创作软件。不是 AI 聊天应用，也不是企业管理后台。

- 靠**表面色阶**建立层次，不靠描边、阴影、渐变。
- 真实内容优先：缩略帧、波形、时间刻度、预览动效、状态标记、指标数字。
- 桌面软件交互：快捷操作、清晰选中态、可预测的面板展开/收起、悬停反馈、搜索筛选、详情检查、直接进入下一步的入口。

### 1.1 颜色：只有一套语义 token，三个主题换值不换名

变量定义在 `src/styles/brand.css`（覆盖 paba 的 `paba/app-slim.css`），主题由 `html[data-theme]` 切换。
**组件只准引用语义变量，不准写十六进制色值。**

| 语义 | 变量 | 深色 dark | 浅色 light | 触感 tactile |
|---|---|---|---|---|
| 页底 | `--bg` | `#000000` | `#e0e2e9` | `#e6e1d5` |
| 面板 | `--surf` | `#0D0D0F` | `#fcfcfd` | `#eae6da` |
| 凹陷/次级面 | `--hole` | `#151517` | `#eef0f4` | `#ddd8c9` |
| 唯一边线 | `--line` | `#2A2A2E` | `#cdcdd6` | `rgba(34,35,31,.18)` |
| 主文字 | `--fg` | `#EDEDED` | `#191a20` | `#22231f` |
| 次文字 | `--dim` | `#9A9A9A` | `#5b5e66` | `#55534a` |
| 占位 | `--ph` | `#6E6E6E` | `#94969e` | `#8a8676` |
| **强调（品牌蓝）** | `--acc` | `#3B8CF8` | `#2F6FE4` | `#f7c948`（黄） |
| 强调按下 | `--acc-d` | `#2E6FD9` | `#1E5BBF` | `#d9a92b` |
| 强调上的字 | `--on-accent` | `#FFFFFF` | `#ffffff` | `#22231f` |
| 选中的底 | `--soft` | `#13233A` | `rgba(47,111,228,.10)` | `rgba(247,201,72,.40)` |

⚠️ **触感主题的强调色是黄不是蓝**——这是有意的（纸 + 墨 + 硬阴影的物理感），组件不要假设强调色一定是蓝。
⚠️ 深色主题必须设 `color-scheme: dark`，否则系统滚动条/表单控件仍按浅色绘制（白竖条就是这么来的）。

### 1.2 语义色

| 用途 | 变量 | 深色 | 说明 |
|---|---|---|---|
| 主操作 / 选中 / 进行中 | `--acc` | 品牌蓝 | 触感主题为黄 |
| 待处理 / 需要用户判断 | `--warn` | `#E0A64B` | **不是失败** |
| 完成 / 已通过 | `--ok` | `#3FBF8F` | |
| 真实失败 / 需关注 | `--bad` | `#F0708C` | |

状态一律**色 + 文字**，不允许只靠颜色。状态语义的唯一来源是 `src/shell/status.ts` 的 `statusOf()`，组件里不准自己写状态色。

### 1.3 字号（目标值；04 期迁移时逐步对齐）

| 用途 | 尺寸/行高 | 现状 |
|---|---|---|
| 元数据 / 时间码 | 11 / 16 | 已在用 |
| 标签 | 12 / 18 | 已在用 |
| 次级描述 | 14 / 20 | 部分页面仍是 13 |
| 默认正文 | 15 / 22 | 部分页面仍是 13 |
| 卡片标题 | 16 / 24 | 部分页面仍是 13–15 |
| 小标题 | 20 / 28 | |
| 页面标题 | 24 / 32 | |
| 首页主标题 | 36–48 | 首页已在用 |

现状：`fm-components.css` 的 [R6] 约定是 11 / 12 / 13 / 17 / 27 五档；三库各写各的。
**层级靠字号、字重、间距拉开，不靠颜色。** 数字 / 时间码 / 文件名用等宽 `.num`。

### 1.4 圆角与间距

**圆角（库层，已基本收敛）**：`--r-ctl 10` / `--r-card 12` / `--r-panel 18(深色)–20(浅色·触感)` / `--r-thumb 5` / `--r-pill 999`。
⚠️ 另有一套 Tailwind 半径 `--radius-sm/md/lg/xl = 4/6/8/12`（`src/index.css` 的 `@theme`），给 shadcn 组件用。**两套并存是当前双轨之一**，01 期收敛为一套。

**间距**：4 的倍数。库层现有 `--gap 16`、`--pad 12/16`。组件内部优先 4–16，同模块 8–16，模块间 24–32。常规页边距 24（窄窗 16）。

### 1.5 控件与动效

控件高度：紧凑 32 / 标准 36 / 主要操作 40。页面顶栏目标 56（现状 `.fx-masthead` 54、`.rfl-head` 44、`.app-header` 60 且不渲染）。

动效曲线沿用 A2：`cubic-bezier(.23,1,.32,1)`。微交互 120–180ms，抽屉/面板 180–240ms。高频操作不配动画。

## 三、可复用组件（复用组件 ≠ 复用布局）

P0（01 期建，清单见 `docs/01期任务单-设计底座与契约.md`）：
`AppShell` · `PageHeader` · `SearchField` · `Toolbar` · `FilterBar` · `StatusBadge` · `EmptyState` · `LoadingState` · `ErrorState` · `DetailDrawer` · `ResourceCardBase` · `ProjectCard` · `AssetCard`

P1（随页面期建）：`EffectCard` · `ReferenceVideoCard` · `WorkbenchPanel` · `GateCard` · `CheckFindingItem`

规则：

1. **页头区**：标题 + 元信息统计 + 右侧主操作；一行说完"这是什么、有多少、能干什么"。
2. **工具栏**：筛选 / 分组 / 排序 / 视图切换，图标+文字，靠左。
3. **状态胶囊**：色点 + 文字，10.5–11px，语义来自 `status.ts`。
4. **详情抽屉**：只统一壳（宽度/标题区/滚动区/底部操作区），**内部结构三库各管**。
5. **空态**：一句话说明为什么空 + 一个能做的动作。
6. **未接入态**：按目标形态画全，动作置灰，旁边一句"XX 未接入"。
7. **破坏性操作确认**：停用/移除前弹确认，说明连带影响（引用方数量）与是否保存。
8. **不做万能卡片**：三库的卡片内容结构各归业务组件；同一模式至少有两个明确使用场景才抽象。

## 四、三主题不是换色，是换材质

| 主题 | 材质语言 | 用在 |
|---|---|---|
| 深色（默认） | 蓝黑表面、单一阴影、边线极淡 | 全站默认 |
| 浅色 | 冷灰纸面（`#e0e2e9`），边线 `#cdcdd6`，白高光内描边 | 明亮环境 |
| 触感 | 奶油纸 `#e6e1d5` + 墨线 + **硬阴影**（`2px 2px 0`，无模糊）+ 黄色强调 | 纸感/印刷感偏好 |

新增样式必须三主题都验过。**不允许只做深色然后让浅色/触感"差不多能看"。**

## 五、截图验收

每完成一个视图：

1. 起 dev server，真机截图 **1920×1080**（上一版写的 1512×950 已不适用）。
2. **深/浅/触感三主题各截一遍**：默认态、选中一项、空态（筛选到无结果）、不可用动作置灰态。
3. 与改动前的提交做**像素对比**（基线拉独立 worktree 单独起服务），只允许动效帧差异（<0.05%）。
4. 核对：状态与真实数据一致、统计随筛选变化、移除/停用后详情与计数同步。
5. 类型检查与构建通过**不算**验收通过。
