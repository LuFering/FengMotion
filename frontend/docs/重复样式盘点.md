# 重复样式盘点（01 期 · Issue 1）

> 基线 `ee1b35f` · 2026-10-22
> 目的：在动手建共享组件之前，把「同一件事有几套写法」数清楚，作为 token 收敛与组件归并的依据。
> 方法：逐文件提取选择器 + 关键声明，同语义归组比对。行号为基线时行号。

---

## 结论（三个数）

1. **5 套并行的 token 命名空间**。paba 基底一套，三个库各一套，工作台两套并存，首页另起一套 `--hf-*`。
2. **同一元素最多 4 套实现**（搜索框 4 套、抽屉 3 套、页头 3 套、空态 8 处）。
3. 卡片容器反而已经收敛（`.mya-card` 与 `.rfl-card` 的 padding/圆角/底色/边线完全一致），说明**归并成本主要在 token、页头、搜索、抽屉、状态词汇，不在卡片**。

## A. token 命名空间：5 套

| 来源 | 变量族 | 与 paba 的关系 |
|---|---|---|
| `paba/app-slim.css`（基底，不改） | `--bg --surf --hole --line --fg --dim --ph --acc --soft --on-accent …` | 基准 |
| `myassets.css` | `--panel --panel2 --line2 --tx --tx2 --tx3 --acc-ink --acc-tx --r-ctl --r-card --r-float --r-panel --r-pill --r-mark --r-scroll --shadow-base/-card-on/-float/-hero/-mid/-seg --eio --eo --gap --pad --sel --raised --scrim --stage-bg --bg-glow --overlay --thumb --media-*` | **另起一套**，与 paba 变量并存但语义重叠（`--panel`≈`--surf`，`--tx`≈`--fg`，`--line2` 无对应） |
| `technique.css` | 同上族，缺 `--pad / --r-float / --r-pill / --overlay`，多 `--fx-bg / --fx-bg-glow / --shadow-ctl / --shadow-overlay / --shadow-raised` | 与 myassets 同族但**不完全一致** |
| `reference.css` | 同上族，多 `--pad / --ph / --thumb / --media-ink-dim / --shadow-card / --shadow-preview`，缺 `--r-float / --r-pill` | 同族，第三份拷贝 |
| `workbench-a2.css` | **paba 变量与 `--panel/--tx*` 同时存在**，外加 `--wb-*` 14 个 | 两套混用，最乱的一处 |
| `home-film.css` | `--hf-*` 24 个，完全独立 | 与上面任何一套都无交集 |

**归并结论**：`tokens.css` 只需要定义**一份**数值 token（间距/字阶/圆角/控件高/动效），并让三库的 `--panel/--tx/--r-*` 别名指向 paba 语义变量；`--hf-*` 与 `--wb-*` 保留为「页面局部皮肤」，不再新增。

## B. 同一元素的多套实现

### B1. 搜索框 —— 4 套

| 实现 | 位置 | 宽 | 高 | 圆角 | 底 | 图标 | 边线 |
|---|---|---|---|---|---|---|---|
| `.fm-search` | `fm-components.css:285` | 190px | min-h 34 | 5px | `--surf` | 15px | `--line` |
| `.mya-search` | `myassets.css:284` | 300px | 30px | `--r-ctl` | `--panel2` | 13px | `--line` |
| `.fx-search` | `technique.css:188` | 320px（`flex:0 0 320`） | 30px | `--r-ctl` | `--panel2` | 13px | `--line2` |
| `.rfl-search` | `reference.css:189` | `flex:0 1 360px`，min 180 | 32px | `--r-ctl` | `--panel2` | 13px | `--line` |

→ 宽 190/300/320/360、高 34/30/30/32、圆角 5 vs `--r-ctl`、底 `--surf` vs `--panel2`、边线 `--line` vs `--line2`。
**归并**：`SearchField` 一个组件，宽度由容器给（不写死），高度/圆角/底/边线走 token；`.fm-search` 退役。

### B2. 页头 —— 3 套

| 实现 | 位置 | 高 | 备注 |
|---|---|---|---|
| `.app-header`（壳层） | `App.tsx:212` 起 | 60px | **实测 9 个路由全部渲染 0 次** —— 死代码（见下） |
| `.fx-masthead` | `technique.css:154` | `flex: 0 0 54px`，padding 0 16 | 特效库自带 |
| `.rfl-head` | `reference.css:141` | `flex: 0 0 44px` | 参考片库自带，带入场动画 |

→ 44 / 54 / 60 三个高度，三套内边距。
**归并**：`PageHeader`（计划第 2.1 节定 56px），`.app-header` 与 `.fx-masthead`、`.rfl-head` 一并退役。

**实测补充（重要）**：`App.tsx` 的 `NO_APP_HEADER` 已经包含 `home / project / assets / methods / knowledge / reference / render`，
而剩下唯一会走 `.app-header` 分支的 `production` 走的是工作台分支 —— 结果是 **`.app-header` 在任何路由下都不渲染**（9 条路由逐一验证 `querySelectorAll('.app-header').length === 0`）。
同理 `.tabbar` 在 9 条路由下都渲染 1 个，但计算样式 `display: none`。

所以「砍顶栏」这条的实质是：**删掉两段死代码**（`.tabbar` 与 `.app-header`），再建真正会用的 `PageHeader`。
这比计划里写的「砍一个正在显示的栏」工作量小，但也要注意：删掉后各页顶部没有替代物，`PageHeader` 必须先就位再删。

### B3. 抽屉 —— 3 套

| 实现 | 位置 | 宽 | 圆角 | 定位方式 |
|---|---|---|---|---|
| `.mya-drawer` | `myassets.css:634` | 380px | `--r-float` | flex 容器内 |
| `.fx-drawer` | `technique.css:772` | 460px | `--r-panel` | flex 容器内 |
| `.rfl-drawer` | `reference.css:1011` | `min(420px, …)` | `--r-panel` | `position:absolute` + `--pad` 四边 |

→ 380 / 460 / 420，两种定位模型。
**归并**：`DetailDrawer` 统一宽度（计划给 440，参考片库 04-C 期再定 560 或全页）、圆角、标题区/滚动区/底部操作区；**内部结构不统一**（三库各自内容）。
⚠️ 计划里素材抽屉写 440、特效写 460、参考片写 560 —— 三个数不统一，01 期要定一个默认宽度 + 允许按库覆盖。

### B4. 卡片 —— 已收敛，只差基类

`.mya-card`（`myassets.css:445`）与 `.rfl-card`（`reference.css:648`）的 `padding: 7px / border: 1px var(--line) / border-radius: var(--r-card) / background: var(--panel2)` **完全一致**。`.fm-project-card`（`fm-components.css:187`）是另一套（项目卡）。

**归并**：`ResourceCardBase` 只做容器/悬停/选中/焦点/操作区，三库卡片内容结构不动。成本最低的一条。

### B5. chips / tag —— 4 套

`.fm-tag`（`fm-components.css:80`，带 `[data-s=done|running|waiting|failed]`）、`.mya-chip`（`myassets.css:238`，带 `[data-on]`）、`.fx-chip`、`.fx-tag`（`technique.css`）。四套各自的选中态写法不同（`[data-on]` / `[data-s]` / `aria-pressed`）。
**归并**：`FilterChip` 一套，选中态统一 `aria-pressed`。

### B6. 状态点 / 徽标 —— 5 套

`.fm-dot`（`fm-components.css:70`，配 `data-s`）、`.mya-status-pill`（`myassets.css:598`，配 `data-s="needs_review|restricted"`）、`.mya-dot`、`.fx-dot`（`technique.css:387`，配 `fx-dot-runnable` 等）、`.rfl-status`。
**归并**：`StatusBadge` 一套，语义**只从 `src/shell/status.ts` 的 `statusOf()` 来**（这是既有唯一来源，不要重造）。

### B7. 空 / 加载 / 错误 —— 8 处

`.fm-empty`（`fm-components.css:117`）、`.mya-empty-*`（`myassets.css:859` 段）、`.fx-empty`（`technique.css:709`）、`.rfl-empty`（`reference.css:806`）、`.fw-ing-empty`（`workbench.css:172`）、`.fw-tray-empty`（`:651`）、`.fw-ref-empty`（`:903`），另有加载/错误分散在各自页面。
**归并**：`EmptyState / LoadingState / ErrorState` 三件套；**加载与错误目前没有统一实现**，这是 01 期新增而不是替换。

### B8. 工具栏 / 筛选条 —— 3 套

`.mya-filterbar`（`myassets.css:195`）、`.fx-filterbar`（`technique.css:323`）+ `.fx-tabs`、`.rfl-*` 工具条（`reference.css:281` 段）。
**归并**：`Toolbar` + `FilterBar`。
