# 工作台预览与编辑区整改清单

目标：围绕“定位问题 → 提出要求 → AI 修改 → 查看结果 → 继续调整”完善工作台。直接编辑能力按项目实际支持情况开放。

- [ ] 1. 收拢轨道界面：暂时收起拆分、复制、删除、移动、裁剪、轨道显隐、静音及吸附；保留定位、时间选区、缩放、循环和可信片段引用。参考轨道下已核对工具、逐帧定位和缩放，可信轨道状态仍待验证。
- [ ] 2. 打通画面引用：排查后端构建及运行版本，验证当前帧、框选区域和基准版本随请求送达 AI；验证失败、追问与草稿保留。源码在同进程项目锁内校验基准版本和图片后再写入目标修改意见；隔离构建中版本冲突与图片校验测试通过。完整后端仍被特效库未完成的 FxCapabilityImporter.Preview 引用阻挡，尚未部署或端到端验收。旧后端暂不能提交画面或时间范围修改，以免绕过版本校验。
- [ ] 3. 完善目标一致性：选区、当前版本和对话引用同步；切换版本或目标失效时清楚提示，避免修改错误版本。已修复画面切换时旧目标残留为上下文，并处理自动出现新版本时的旧画面目标；真实项目中手动切换验证通过，自动新版本场景仍待端到端验证。
- [ ] 4. 完善修改结果审阅：真实修改后关联原意见、AI 回复、版本和目标位置；项目级保存记录，并验证前后对比与继续调整。
- [ ] 5. 按项目能力展示工具：明确仅视频、可信轨道、可直接编辑等能力，缺少可靠结构时降级并解释原因。
- [ ] 6. 完善版本与导出：明确当前查看版本、最新版本和导出对象；核对版本恢复、导出结果和错误反馈。
