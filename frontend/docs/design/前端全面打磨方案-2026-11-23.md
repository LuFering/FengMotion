# 前端全面打磨方案 · 2026-11-23

状态：**待作者审阅**。审阅通过后作为实施依据。实测底稿见 [实测记录](前端全面打磨-实测记录-2026-11-23.md)，本文只写结论和要做的事。

范围：React 主前端 `frontend/` 的全部界面。不改后端、不改数据语义；已验收的复刻页（交付 `RenderDelivery`、项目指挥中心）不动内部。

## 0. 原则

1. **不另起风格**。以运行中的代码为准：V3 token（`--tx/--panel/--line/--acc…`）、深色 / 浅色 / 触感三套主题、最近几轮已确认的做法（画面是主角、一处信息一个位置、默认状态不上色、主操作唯一）。
2. **先统一，再打磨**。同一类控件全站只有一个实现；各页只调布局，不再各写一套下拉、弹窗、播放条。
3. **如实**。未接入的能力画出来、置灰、写原因；演示数据标明演示。
4. **加东西要有用**。新增的交互都对应实测里一个具体的卡点（误操作无法撤销、找不到当前位置、两套播放条打架等），不加装饰性效果。

## 2. 统一 UI 规范（替换 `design-system.md` 里已过时的部分）

### 2.1 颜色 token：收成一个来源

- 现状：V3 页面层（`--tx/--tx2/--tx3/--panel/--panel2/--raised/--line/--line2/--hover/--acc-ink…`）在素材、工作流、参考片库、特效库、工作台五个文件里各写一遍，**三主题取值完全一致**。
- 做法：新建 `src/styles/theme-v3.css`，按 `html[data-theme]` 定义一次，五处删掉重复定义。零视觉变化。`--line` 统一为一个透明度（深 .06 / 浅 .06 / 触感 .16，按现在最多的值）。
- 状态色只表状态：`--ok` 完成、`--warn` 待你决定、`--bad` 失败。**装饰一律用 `--acc` 或中性灰**。涉及：工作流节点缩略图与画布节点（审片琥珀框、交付绿底）、特效详情「适合」绿签。
- 画面上的控件（海报卡按钮、影院浮层）固定用深色玻璃 + 白字，三主题一致（已在素材、特效、参考片库落地，作为规范写下）。
- 第三方嵌入组件（LeiBox 输入框）不写死颜色：宿主传 `--lbx-*`，浅色分支也要传，不再「保持默认设计」。

### 2.2 字阶：按实际使用定，改写 `tokens.css`

`tokens.css` 现有字阶（正文 15、次级 14）全站只被引用 21 次，实际主力是 11 / 12 / 13。改为：

| token | 值 | 用途 |
|---|---|---|
| `--fm-text-page` | 25 / 550 | 库级页面标题（特效库、素材、工作流已是此值） |
| `--fm-text-view` | 15 / 600 | 面板、详情、弹窗标题 |
| `--fm-text-body` | 13 / 400 | 正文、名称 |
| `--fm-text-sub` | 12 / 400 | 次要正文、列表值 |
| `--fm-text-meta` | 11 / 400 | 元数据、时间码、计数 |
| `--fm-text-mini` | 10.5 / 500 | **下限**：铭牌、角标、刻度、键帽 |

- 全站 9px（61 处）、8px（5 处）、9.5px、10px（188 处）升到 10.5 或 11；11.5 / 12.5 / 13.5 / 13.02 / 12.555 这类非档位值归档。
- 数字用 `font-variant-numeric: tabular-nums`，**不用等宽字体**；等宽只给代码与文件路径。
- 衬线字体只用于首页品牌标题。
- 侧栏文字 9px → 10.5px（「我的创作」4 字在 68px 轨里放得下）。

### 2.3 圆角、间距、动效

- 圆角四档已定：标签 4 · 控件 6 · 卡片 10 · 面板 14（触感 20）。旧名 `--r-ctl`（96 处）、`--r-card`（34）、`--r-panel`（13）改为指向新档的别名，再逐页替换。
- 动效：`--eo`（260 处）改为 `--fm-ease` 的别名。颜色、透明度过渡 .15s，面板 .22s；不加上浮、发光。
- 焦点环：全站 `2px solid var(--acc)`、偏移 2px，只在 `:focus-visible`。

### 2.4 共享控件（每类只一个实现）

| 控件 | 实现 | 替换范围 |
|---|---|---|
| 单选下拉 | 把特效库的 `FxMenuSelect`（基于共享 `DropdownMenu`）提到 `shared/components/MenuSelect` | 14 处原生 `<select>`：素材 5、工作流 7、场景编辑器 4、首页创作 1、工作台 1、待发送 1；参考片库片库覆层的筛选也换 |
| 弹窗 | 共享 `Dialog`：遮罩 `rgba(5,5,8,.52)`、不模糊、Esc / 遮罩关闭、关闭键读屏「关闭」 | 待发送、设置、各页自造弹窗逐个核对 |
| 提示 | 共享 `toast` 增加**撤销**动作：`toast(text, { action: { label: '撤销', run } })` | 加入 / 移出待发送、收藏、删除片段、移至项目 |
| 播放条 | 新建 `shared/components/MediaTransport`：播放、进度（悬停时间气泡）、时间读数、静音，样式取参考片库已确认的细线时间轴 | 素材详情、工作台「成片」模式（替换浏览器原生 `controls`） |
| 时间格式 | `formatClock` 从参考片库提到 `shared/lib/time.ts` | 工作台、场景编辑器、素材、待发送；`0:04`、`0:04.5`、时长「4 秒」 |
| 空 / 读取中 / 失败 | 共享 `EmptyState / LoadingState / ErrorState` + 同尺寸骨架 | 各页核对，自造的换掉 |

### 2.5 时间码

界面上不再出现 `00:30:00` 这种「分:秒:帧」写法（读成 30 分钟）。播放读数写 `0:03.4 / 0:30`；需要帧精度的地方（工作台时间线悬停、场景编辑器入出点）在数值旁写「第 102 帧」。总时长全页只取一个来源。

## 4. 实施顺序与提交批次

每批完成后：类型检查、正式构建、lint 不新增，浏览器 1069×681 与 1440×900 × 三主题核对，按批单独提交（不混入工作区里已有的工作流、设置、后端未提交改动）。

1. **基础**：`theme-v3.css` 收口；`tokens.css` 字阶改写、旧名改别名；`MenuSelect`、`MediaTransport`、`formatClock` 提到 shared；`toast` 撤销。
2. **导航壳 + 待发送 + 设置**（含两处导航缺陷）。
3. **首页 + 对话**（含 LeiBox 主题、`--cv-raised`）。
4. **工作台 + 场景编辑器**（播放条合一、时间码、字号）。
5. **工作流**（列表 + 编辑器）。
6. **素材、特效库、参考片库**。
7. **文档**：改写 `design-system.md` 为本方案 §2；`interface-polish.css` 的跨页补丁拆回各页（只搬家，不改值）。

## 5. 需要你拍板

1. **首页右上与标语**：右上只留「GitHub」；标语候选——「一句话说清想要什么，剩下的交给它」/「从一句话，到能交付的片子」/ 保留原句只去掉英文。
2. **工作台播放控制留哪套**：建议留时间线顶部那套（贴着轨道，带切点跳转），监看器底部改为只显示读数的细线；成片模式换 `MediaTransport`。
3. **工作流编辑器节点库**：已有节点的流程默认收起，还是保持展开。
   - **已定（2026-11-24）**：空流程默认展开；已有节点的流程按上次开关（默认收起）；窄于 760px 一律收起。
4. **「社区」占位**：降权保留在导航，还是收进「更多」。
   - **已定（2026-11-24）**：降权保留在导航：图标与文字 .55 透明度、「开发中」角标，悬停不提亮，点击只提示不跳转。
5. **参考片库播放条 68px 缩进**：对齐时间轴，还是保持（随侧栏补偿）。
   - **已定（2026-11-24）**：播放时只淡出导航，片名、播放条、时间轴、片单不左移，始终留在侧栏安全区内、左边对齐；不再伸进淡出后仍接收指针的导航区域。

## 6. 不做

- 后端字段（技法中文名、片段关键帧等，已记入各库契约）。
- 交付、项目指挥中心等复刻页内部。
- 新页面、新导航结构。
