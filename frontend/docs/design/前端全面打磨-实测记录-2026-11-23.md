## 1. 导航壳

- 侧栏文字 9px（`.hm-nav-text`），低于全站最小 10.5px。
- **缺陷**：在三库内时「更多」带 `aria-current=page`、竖条是蓝的，但文字与图标是灰色——`.hm-nav a, .hm-nav > button { color: var(--dim) !important }` 压过了 `.nav-leaf[aria-current="page"] { color: var(--acc) }`。结果：人在素材/参考片/特效库时，侧栏没有一项亮起。
- **缺陷**：`shared/icons/NavGlyph.tsx` 把特效库 `panels-top-left` 映射成 `MessageCircle01`，与「我的创作」同一个对话气泡图标（「更多」抽屉里特效库那一行）。
- 「更多」抽屉：居中于侧栏旁的小浮层 202 宽，三行（图标 + 名称 + 一行用途 + 「当前」签），观感干净，保留；用途说明 10.5px。
- 「社区」是占位项（点了只提示），在导航里与真实入口同权重。

## 2. 首页

结构：单屏（不滚动）。左：品牌行 + 输入框（逐字打出的示例需求轮播）+ 快捷键提示；右：衬线大标题「从一句话，到一条片子」+ 手绘弧线 + 旋转印章 ↔ 演示片轮播。

**有创意，保留**
- 衬线大标题 + 手绘弧线下划线 + 旋转印章，与演示片交替：有品牌气质、不落卡片仪表盘。
- 输入框占位逐字打出不同需求示例：教用户能说什么，比静态提示好。
- 触感主题的实边硬阴影输入框。

**平庸 / 不精致**
- 印章「FENG MOTION」7px，看不清。
- 右上「欢迎关注作者 (๑•ᴗ•๑)」颜文字与专业工具气质不符；仅一个 GitHub 链接却配一句招呼。
- 标语「让 AI agent 用一行行代码，重新定义你内心的小巧思」中英混排、偏技术说明。
- 快捷键提示字小、对比低（深色下几乎看不见）。
- 浅色主题输入框投影 `0 24px 55px` 过大，像一块底板。
- 模型选择胶囊三主题都是蓝色光圈，触感主题强调色是黄，不符主题。
- 1440 宽下左右两栏重心偏低（输入框中心约 y=450，标题约 y=400），右上角落空。
- 字体三种混用（衬线标题 / Geist / 等宽），等宽用途待查。

## 3. 我的创作（对话）

结构：顶栏（项目名 + 对话/工作台分段）→ 对话流（AI 回复、已编辑文件卡、产物卡、回复操作）→ 底部吸附输入区（模式：普通对话 / 修改工程 / 只提问；LeiBox 输入框在 Shadow DOM 内）。

**有创意，保留**

- 「产物」卡：成片直接出现在对话里，可点进工作台。

- 模型胶囊的旋转光边（首页同款）——但颜色要跟主题（见下）。

**平庸 / 不精致**
- 文件行每行都带 `未命名项目-1795024637255/` 前缀（`.fc-dir`），文件名被挤到后面；应弱化或折叠公共前缀。
- 回复下方元信息「5 天前 · 1766k tok」用等宽小字，和正文不在一个字阶。
- 字号混用 14 / 13.02 / 13 / 12 / 11 / 10，正文 14 与规范 13 不一致，13.02 是计算残差。

- 触感主题：输入框实边 + 3px 硬阴影、「对话」分段黄色，到位；模型胶囊光边仍是蓝色（与首页同一问题，`leiboxStyles.ts` 胶囊光效写死 `--lbx-engine-color` 引擎色，不随主题强调色）。
- 浅色主题：页面 `#e0e2e9`、文件卡/产物卡随主题，正常；输入框是 `#fff` + `#e5e7eb` 描边（第三方默认灰），与页面卡片描边 `rgba(25,25,50,.09)` 不是一套——LeiBox 浅色分支「保持默认设计」的直接后果。
