# 参考片库打磨方案 · 2026-11-23

状态：本轮实施依据。适用 `frontend/src/features/reference/`。配套契约见 [参考片库界面契约](../contracts/reference-library-ui.md)；数据语义以 [library.md §4–§5](../contracts/library.md) 为准，不改。

## 1. 参考片库是什么、用来做什么

- **视觉探索型**的库，回答「有什么值得借鉴」，主要动作是**发现、比较、分析、引用**（knowledge-library-spec §二）。
- 内容分三层：**参考片 → 片段（时间范围）→ 分析（六维：运镜/构图/光线/节奏/转场/可借鉴点；每维有来源、置信度、证据）**。
- 用户主线：**看片 → 在想借鉴的位置标出片段 → 看/写分析 → 交给创作（待发送）或工作流**。
- 铁律（library.md §4.2.3、页面职责合同 §1.3）：
  - 观察与推断分区块；推断只读。
  - 未分析的维度显示「待分析」，不填默认值；模型判断与实测可区分。
  - 解析能力未接入时，界面按目标形态画出来，动作置灰并写明「分析未接入」，不隐藏也不假装。
- 形态：2026-10-23 定版的**影院形态**——画面铺满，片名、操作、分析、片段条、片单都浮在画面上；库功能收进「片库」覆层。本轮**保留形态**，只打磨。

## 2. 现状问题（2026-11-23 实测：1440×900 / 1069×681，深色与浅色，真实库 1 条参考片、1 个片段、0 个集合）

### 2.1 错误（必须修）

| 位置 | 问题 | 原因 |
|---|---|---|
| 片库卡片 | 每张卡左上角露出一行源码 `filmOf(s.videoId)?.thumbnailUrl ?`，缩略图不显示 | JSX 里三元表达式没包 `{}`，被当成文本 |
| 参考集合页签 | 列出 9 个演示集合，真实库一个都没有 | 集合名单读的是演示常量 `REFERENCE_COLLECTIONS`，成员数读服务端，两边对不上；违反数据真实性 |
| 时间码 | 4 秒的片段写成 `00:04:00 – 00:08:00`，读起来像 4 分钟 | 格式是「分:秒:帧」，第三段帧号与「时:分:秒」同形 |
| 播放条说明 | 真实导入的视频写着「动态示例 · 静音连播…」 | 说明文案是演示期遗留，常驻且不准确 |
| 闲置淡出 | 暂停时 3 秒后片名与操作也会消失 | 闲置判断没看是否在播放 |
| 下一片段按钮 | 分析面板打开时被面板盖住，点不到 | 固定在画面右侧中部，与面板重叠 |

### 2.2 体验与观感

| 位置 | 问题 |
|---|---|
| 顶部操作 | 6 个按钮一排；「片库」与「搜索与筛选」打开同一个覆层；「收藏」是片段级动作却放在片级工具栏；「选择片段」只在片库覆层里才有意义 |
| 片名区 | 元信息「本机导入 · 片段 1 / 1 · 待分析 · 6 项待分析」，「待分析」写两遍 |
| 片段条 | 一个 4 秒片段铺满整条，看不出它在 12 秒视频里的位置；条与时间无关，等于没有时间轴 |
| 分析面板 | 维度下挂 9px 解释字（镜头怎么动…），读不清也不必要；时间码 10px；「可复用」单独套框；没有「开始分析」入口，也没说明为什么全是待分析 |
| 分析面板 | 主按钮「用作参考」语义不清：实际是写入工作流取用清单；而「加入待发送」只在片库卡片上有，面板里反而没有 |
| 人工记录 | 标签「你看到的画面（观察）」「建议怎么用（建议）」冗长；起止输入没有单位；「删除片段」与范围输入挤在一行 |
| 片库覆层 | 运镜、转场、状态、排序是系统原生下拉；运镜/转场在没有已分析片段时只有「全部」一个选项；卡片文字 9px |

## 3. 设计方向

沿用工作台、素材页、特效库三轮的做法：

1. **画面是主角**，控件少而准；同一动作只有一个入口。
2. **片级 / 片段级分开**：顶部只放片级动作（导入、片库、分析面板开关）；收藏、待发送、工作流、分析都归到片段所在的面板。
3. **时间是参考片的骨架**：片段条改成真正的时间轴，位置、长度、播放头与视频时长一致；时间码统一成人能读的 `分:秒`。
4. **如实**：未接入的能力画出来、置灰、写一句人话；空集合不显示演示数据。
5. **层级靠字号、字重、灰阶**；最小字号 10.5px；不加框套框。

## 4. 具体改动

### 4.1 修错
- 片库卡片缩略图三元表达式补 `{}`。
- 参考集合只用服务端 `GET /reference-collections` 的名单；为 0 时页签不出现（当前没有创建集合的界面，出现只会通向空页）。
- 新增 `formatClock`：`0:04`、`1:05`；非整秒保留一位小数 `0:04.5`；时长写「4 秒」。`formatTimecode`（分:秒:帧）保留给工作流等已有调用方，参考片库界面不再用。
- 删除播放条常驻说明；快捷键写进按钮 `title`。
- 闲置淡出只在**播放中**生效。

### 4.2 顶部
- 片名区：小标题「参考片库」10.5px；片名 26px/600；元信息一行「来源 · 时长 · N 个片段 · 视频状态」，状态只写一次。
- 操作：`导入视频`（主）· `片库`（带搜索图标，搜索、筛选、收藏、集合都在里面）· `分析`（面板开关）。「搜索与筛选」并入「片库」；「选择片段」移进片库覆层头部；「收藏」移进分析面板。

### 4.3 时间轴（原片段条）
- 轨道 = 整条视频时长；片段按 `start/end` 定位，最小可见宽 6px；当前片段高亮；播放头竖线随播放移动。
- 点轨道空白处跳到该时间；点片段选中并跳到起点。
- 轨道上方一行：`播放` · `上一片段` `下一片段` · `+ 标记片段` · `0:04 / 0:12`。原画面中部的左右大圆按钮移除（←/→ 仍可用）。
- 片段标签：宽度够时显示「片段 1」，不够时只显示序号。

### 4.4 分析面板
- 头部：「片段 1」+ 状态签；下一行 `0:04 – 0:08 · 4 秒`（12px，正文字体）。
- 操作行：**加入待发送**（主，实底）· 用于工作流 · 收藏（图标按钮）。已加入时主按钮变「已在待发送」并禁用。
- 六维改为两列定义列表：维度名 12px（去掉 9px 解释字，解释放 `title`）；值 12.5px；来源签「实测 / 模型 / 人工」10.5px。「可借鉴点」作为第六行，不再单独套框，值较长时独占整行。
- 全部维度待分析时，维度列表上方一行：置灰的「开始分析」按钮 + 灰字旁注。旁注取 `GET /capabilities` 的 `referenceAnalysis.note`（当前「参考片解析未接入」），后接「可在下方手动记录」。能力可用时按钮可点。
- 人工记录：标签「观察」「用法建议」，各自占位文字给例子；「模型推断」只读块放在两者之间，标「模型」。
- 片段范围：`起点 [4.0] 秒 – 终点 [8.0] 秒`；「删除片段」移到面板最底部，次要文字按钮，悬停变红。

### 4.5 片库覆层
- 头部：标题「参考片库」· 页签（全部片段 / 收藏 / 最近浏览 / 参考集合*）· 右侧「选择」「关闭」。
- 工具行：搜索 · `运镜 ▾` `转场 ▾` `状态 ▾` · 计数 · `排序 ▾`（右）。下拉用共享单选菜单（与特效库同款）；没有可选值的筛选不出现。
- 卡片：16:9 画面铺满；左上「片段 1」+ 时长；底部两行：片名 13.5px/550；`0:04 – 0:08 · 运镜值或「运镜待分析」` 11px；状态签仅在 `partial/pending` 时出现在右下，10.5px。
- 空结果：一句话 + 「清除筛选」。

### 4.6 片单（底部横条）
- 保留；卡宽 168 → 160，选中改 2px 强调色内描边；副标题「N 个片段 · 0:12」。

## 6. 本轮不做（需要后端，写进契约）

- 片段关键帧缩略图（当前卡片只能用整片封面，同一视频的片段看起来一样）。
- 新建集合、把片段加入集合的界面（接口已有，界面另开一轮）。
- 相似片段、语义检索。

## 7. 验收

- 1069×681、1440×900；深色、浅色、触感三套主题。
- 片库卡片不再出现源码文本，缩略图正常；参考集合页签在 0 个集合时不出现。
