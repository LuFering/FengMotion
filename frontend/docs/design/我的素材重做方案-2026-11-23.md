# 我的素材重做方案 · 2026-11-23

状态：本轮实施依据，替代 [2026-11-21 方案](我的素材重做方案-2026-11-21.md) 的视觉与交互部分；素材的定义、五维状态和待发送语义沿用，不改。适用 React 主前端 `frontend/`。配套契约见 [素材界面契约](../contracts/assets-ui.md)。

## 1. 素材是什么、用来做什么

- **工作区级的真实文件库**：图片、视频、音频、字体、文档。来源有三种：导入、生成结果、内置。素材不属于某个项目，项目通过引用使用它。
- **加入待发送**：把素材暂存为下一次创作对话的输入。它不等于已经发给 AI，也不会给项目新增引用。
- **登记为参考片**：视频的另一项显式动作，交给参考片库，不宣称已经分析。
- **五维状态互相独立**：处理、审核、可用性、授权、引用。审核通过不代表授权可用。

用户的主线只有一条：**导入 → 找到 → 看清 → 加入待发送**。收藏、文件夹、标签、改名、授权与审核都是管理动作，界面上要排在主线之后。

## 2. 现状问题（2026-11-23 实测：1059×681、1440×900，深色与浅色）

| 位置 | 问题 | 原因 |
|---|---|---|
| 卡片 | 每张卡都挂一个橙色警告图标 | 「授权未知」是新导入素材的默认值，三项全是未知。人人都有的提示没有区分作用，只是噪音 |
| 卡片 | 「图片 / 视频」类型行和文件名、缩略图重复表达 | 同一信息出现三次，违背「一处主位置」 |
| 卡片 | 透明图片的棋盘格又灰又大，比图片本身还抢眼 | 明暗两格对比过强，浅色主题下像一块深灰补丁 |
| 卡片 | 视频时长放在卡片文字区右上角 | 用户找时长会看画面角落，不会看文字区 |
| 卡片 | 悬停按钮是面板色实心方块 | 盖在画面上显得厚重，和画面脱节 |
| 工具条 | 两行：标题+计数+排序+视图，下一行类型页签+批量选择 | 「3 项」和「全部 3」重复；音频、字体、文档都是 0 也全部列出 |
| 列表 | 名称列只有 150px，文件名被截成「fengmotion-…」；操作列被裁掉 | 10 列平分宽度，名称列没有优先级 |
| 列表 | 每行都是「未知」「未提审」两颗彩色胶囊 | 默认值也上色，异常反而不突出 |
| 详情 | 收藏、重命名、复制地址、参考片、删除挤成两行，删除夹在中间 | 五个次要动作平铺，危险动作没有隔离 |
| 详情 | 文件信息全用等宽字体，日期是「2026/11/5」 | 看起来像调试面板；日期写法和工作流列表的「11月19日 08:54」不一致 |
| 详情 | 「格式 video/mp4」和标题下的「MP4」重复 | MIME 是技术信息，不该占主位置 |
| 分类栏 | 页脚「184 KB · 共 3 项」先说大小 | 用户先关心有几项 |

## 3. 设计方向

画面是主角，界面退后。和创作工作台那轮打磨用同一套做法：

1. **一处信息一个位置**。类型由格式铭牌表达，时长贴在画面上，计数只在标题旁出现一次。
2. **默认状态不上色，只有异常才提示**。授权未知、未提审是常态，卡片上不提示；处理失败、限制使用、未通过、需复核、需署名才出现，而且用「圆点 + 文字」，不只靠颜色或图标。
3. **主操作唯一**。整页唯一的实心按钮是页头的「导入素材」；详情里唯一的实心按钮是「加入待发送」。其余是次要按钮或收进「更多」。
4. **层级靠字号、字重和灰阶**。不加框套框，不用渐变和发光。
5. **可读优先**。正文 13px，元信息 12px，11px 只给铭牌和角标。数字用等宽数字（tabular-nums），不用等宽字体。

## 4. 页面结构

```
┌ 页头：我的素材                              [搜索名称或标签  /] [+ 导入素材] ┐
├ 分类栏 208 ┬ 浏览区 ──────────────────────────────────────────┬ 详情 320 ┤
│ 全部素材 3 │ 全部素材 3   [全部][图片 2][视频 1]   排序▾ [▦][≡] [选择] │ 预览      │
│ 收藏       │ ─────────────────────────────────────────────── │ 名称      │
│ 最近使用   │ ┌────────┐ ┌────────┐ ┌────────┐                  │ 规格      │
│ 文件夹     │ │ 画面   │ │ 画面   │ │ 画面 0:12│                │[加入待发送][☆][⋯]│
│ 来源 ›     │ └────────┘ └────────┘ └────────┘                  │ 信息      │
│ 授权与审核›│  名称        名称        名称                      │ 标签      │
│ 3 项·184KB │  PNG·1423×915·117 KB …                          │ 授权与审核│
└────────────┴─────────────────────────────────────────────────┴ 使用位置 ┘
```

### 4.1 页头
- 标题「我的素材」20px/600。搜索框 36px 高、最宽 400px，占位改为「搜索名称或标签」（授权说明仍可搜，不在占位里罗列）。
- 「导入素材」是整页唯一的实心主按钮。

### 4.2 分类栏
- 顶部只留收起按钮和小标题「分类」。
- 三组：库（全部素材 / 收藏 / 最近使用）、文件夹（含新建）、可折叠的「来源」和「授权与审核」。当前所在分类所属的组自动展开。
- 计数右对齐、等宽数字；0 项的智能分类降低透明度但保留。
- 页脚改为「3 项 · 184 KB」。

### 4.3 浏览工具条（一行）
- 左：当前范围名 15px/600 + 计数（12px 灰）。有筛选时出现「清除筛选」文字按钮。
- 中：类型筛选。只列出数量大于 0 的类型和当前选中的类型；「全部」不带数字（避免和标题计数重复）。
- 右：排序（「最近导入 / 最近使用 / 名称 / 文件大小 / 时长」）、网格/列表切换、「选择」。
- 浏览区宽度不足时类型筛选换到第二行。

### 4.4 素材卡（2026-11-23 修订：改为海报式，对齐特效库 `.fxc-poster`）
- 画面铺满整卡（16:10，最小列宽 216px，常见宽度每排 4–5 张），文字压在底部深色渐变上，白色系文字，三套主题一致。
- 两行：文件名（13px/550）/ 格式 · 时长 · 尺寸 · 大小 · 引用（11.5px）；有异常时名称上方多一枚状态签。
- 下列旧条目中「文字区两行」「状态签在画面左下角」「时长贴在画面右下角」作废，其余沿用。
- 画面 16:10，图片 `contain`，视频封面 `cover`。
- 透明图片的棋盘格改为低对比细格（深色主题贴近面板色，浅色主题贴近白色），只做「这里透明」的暗示。
- 视频时长贴在画面右下角，半透明深底白字；悬停静音预览保留。
- 画面上的悬停控件：左上勾选框，右上「加入待发送」「收藏」。控件用半透明深底 + 白色图标，28px，不再用面板色实心方块。已收藏、已在待发送时常驻显示。
- 文字区两行：
  - 第一行：文件名 13px/550，单行省略，悬停有完整名。
  - 第二行：`PNG · 1423×915 · 117 KB`（12px 灰）；右侧被引用时显示「🔗 1」。
- 异常提示：在第二行下方出现一枚「圆点 + 文字」的状态签（如「需复核」「限制使用」「处理失败」「需署名」）；没有异常就不出现，卡片高度保持一致（预留不占位，见实现）。
- 选中（查看详情）：强调色描边；批量勾选：勾选框实心 + 描边。

### 4.5 列表视图
- 列：勾选 | 名称（缩略图 + 文件名 + 格式铭牌，弹性宽度，最小 240px）| 时长/尺寸 | 大小 | 来源 | 授权 | 审核 | 引用 | 操作。
- 去掉单独的「类型」列，类型由缩略图和格式铭牌表达。
- 授权、审核用纯文字：默认值（未知、未提审）用最浅灰；需要处理的值带彩色圆点。
- 操作列固定在右侧，始终可见。浏览区窄时依次隐藏「来源」「引用」。
- 行高 52px，缩略图 48×32。

### 4.6 详情
- 预览 16:10。
- 名称 15px/600，可点「重命名」原地编辑；名称下一行：`MP4 · 640×360 · 0:12 · 24 KB`。
- 操作行：「加入待发送」（实心，占满剩余宽度）+「收藏」图标按钮 +「更多」图标按钮。更多菜单里：重命名、复制文件地址、登记为参考片（已登记时显示「已在参考片库」并禁用）、分隔线、删除（红色，二次确认）。
- 「信息」：文件夹（可改）、来源、格式（只写 MP4，MIME 放悬停提示）、尺寸、时长、大小、添加时间、最近使用。值用正文字体 + 等宽数字；日期统一为「11月5日 14:20」，跨年写「2025年11月5日」。
- 「标签」「授权与审核」「使用位置」三段沿用现有能力，只调整排版。

### 4.7 批量操作坞
- 结构沿用。按钮高度、圆角与页面统一；「删除」移到最右侧分隔线之后；主按钮「加入待发送（n）」。

### 4.8 空态、加载、错误、导入
- 文案沿用，空态主按钮与页头一致。导入进度条与浏览区对齐，失败项可重试。

## 5. 视觉规范（本页作用域 `.mya-library`）

| 项 | 值 |
|---|---|
| 页边距 / 面板间距 | 24px / 16px |
| 分类栏 / 详情宽 | 208px / 320px |
| 圆角 | 面板 14、卡片 10、控件 7、画面内角标 5 |
| 字号 | 页标题 20/600；范围标题 15/600；正文与名称 13；元信息 12；铭牌角标 11 |
| 灰阶 | 名称 `--tx`；元信息 `--tx2`；默认状态与占位 `--tx3` |
| 实心按钮 | 沿用 `--action-fill`（深色 #2465cc，白字 5.51:1）；触感主题沿用黄色 |
| 画面内控件 | `rgb(10 11 14 / .62)` 底、`rgb(255 255 255 / .14)` 描边、白色图标 |
| 动效 | 只做颜色与透明度过渡 .15s；不做卡片上浮和图片放大 |

## 7. 本轮不做

- 不改后端，不加新接口；透明通道检测、服务端分页搜索、虚拟列表另行设计。
- 不改待发送抽屉和导航入口。
- 不改五维状态的语义和审核流转规则。

## 8. 验收清单

- 1059×681、1440×900 两档，深色、浅色、触感三套主题截图核对。
- 卡片：无异常素材不出现状态签；构造异常（列表内存夹具）时状态签有文字。
- 列表：文件名在 1440 宽下完整显示常见长度；操作列不被裁切。
- 详情：操作行单行；更多菜单可键盘打开、Esc 关闭且不连带关闭详情。
- 测试、构建通过，lint 不新增。
