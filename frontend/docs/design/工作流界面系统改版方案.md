# 工作流界面系统改版方案

日期：2026-11-17。状态：方案已实施，本轮界面与交互验证见文末「实施与交付记录」；保留的执行器与验收边界单列。

## 本次要求与优先级

用户要求系统改版工作流首页、新建页、React Flow 编辑器。必须保留节点拖拽、端口连线和自由编排；不得改成向导或步骤卡，不得将「工作流」改名为成片配方、制作方案等名称。

目标是让现有节点编辑器更专业、更好上手、更流畅，并与 FengMotion 其余界面保持一致。降低理解成本应靠清楚的空间组织、节点反馈与直接操作完成，不能靠删掉画布完成。

本次依据：PRODUCT.md、页面职责合同.md、workflow-spec.md、前端设计原则与已确认界面.md、工作流与创作工作台边界待讨论.md，以及 Workflow.tsx、WorkflowEditor.tsx、workflowService.ts 和用户三张批注截图。旧规范中的简化使用页可作为后续辅助入口，不能替代本次明确保留的画布编辑器。边界讨论文档不是已批准的架构迁移。

## 当前事实与边界

- 原生首页、新建页和 React Flow 编辑器已经存在。节点、连线、配置、撤销重做、布局和本浏览器保存是已有基础，不能重做外观时损坏。
- 首页卡面主要由序号、轮换颜色和抽象符号组成，没有准确表达各工作流结构差异。
- 新建页按两种流程重复展示题材预设，混排可创建与规划中内容。题材图片不能作为该工作流真实产物的证据。
- 编辑器已有构建栏、画布工具条、按选择出现的检查器、执行抽屉，适合重新组织层次，无需换掉画布引擎。
- 当前运行能力混合：关联项目的自由创作节点可调用真实创作与渲染，其他节点主要记录快照，分阶段流程主要评估状态。自由连线不等于任意图均可真实执行。
- 工作流及运行记录目前保存在浏览器。服务端定义版本快照、完整通用执行器、明确的跨项目应用流程，不能在本轮 UI 中冒充已完成。

## 三个界面的改版方向

### 1. 工作流首页：找到、辨认、继续编辑

- 保留「工作流」、搜索、新建工作流；取消占据首屏的宣传横幅和无意义装饰。
- 卡面优先显示真实节点与连线的轻量静态缩略图；有明确关联的真实产物时可显示产物封面，并标清其所属运行。没有产物时不配无关图片。
- 结构缩略图不为每张卡挂载一套交互 React Flow。可由已保存节点位置与边生成 SVG，限制复杂图的缩略细节，避免列表占用大量资源。
- 卡片保留名称、简短用途、节点数、最近编辑或运行、项目关联及必要能力状态。复制、删除归入次级操作，打开编辑器为主操作。
- 「我的工作流」「最近使用」有真实数据才呈现相应结果；未开放社区不占据主要操作路径。

### 2. 新建工作流：提供起点，随后直接进画布

- 不增加多步向导。提供空白工作流及已有真实可用预设，选择后直接打开节点画布。
- 预设用真实初始结构、用途与输入要求帮助判断，不用库存人物照暗示能生成对应影片。
- 规划中内容不与可用预设等权展示；作为次级信息保留，不让大量禁用卡占满首屏。
- 自由创作、分阶段评估的差别在选择处说清，不把题材选择等同执行能力。
- 若当前空白图执行不受支持，应允许编辑保存，并在运行前列出缺少的节点或输入，不能用默认流程偷偷替换。

### 3. 编辑器：画布为中心，工具围绕选中对象

- 顶栏集中工作流名称、定义版本、保存状态、关联项目、运行入口；次级操作收敛到运行记录与更多菜单。
- 左侧集中节点库与资源，减少与画布重复的常驻信息；支持搜索，保留点击添加，并逐项核实节点拖入画布的支持情况。
- 中央完整保留 React Flow：节点拖动、端口连线、平移缩放、多选、删除、撤销重做、整理与适应画布。操作快捷提示按需出现，不长期遮挡。
- 节点采用统一标题、简短配置摘要、输入输出端口、真实状态；长提示词与复杂参数放右侧检查器。缺输入与连线错误应定位到具体节点或端口。
- 右侧按选中节点显示设置、输入、输出；未选中不占据大块空白。窄窗口用可收起面板，优先保住画布。
- 下方执行区默认紧凑，运行时显示当前节点、真实反馈与错误；查看详情时再展开，不用虚构进度和装饰性流光代表执行。
- 真实执行、演示、尚未接入在节点与运行入口附近明确区分。未关联项目时，不能把演示运行包装成制作成功。
- 工作流定义版本、一次运行、项目视频版本分开表达，不混用数字或状态。

## 视觉与性能原则

- 继承现有品牌蓝、中性底色、字体、按钮、表单与焦点规范，不另起一套品牌皮肤。
- 以对齐、密度、留白、细边界建立层级，取消无意义的彩色封面、星形符号、装饰轨道与持续发光。
- 节点颜色只辅助识别类型或真实状态，文字和图标同时说明状态。
- 对节点组件、派生状态、回调与订阅做实际性能检查；高频运行日志不应迫使整个图反复重绘。
- 拖动和缩放期间避免高成本阴影、滤镜和布局动画；悬停效果优先使用透明度和变换。是否启用可见节点渲染需用复杂图实测，不预先承诺优化收益。

## 与创作链路衔接

首页管理可复用工作流定义；编辑器调整结构与配置；项目提供一次执行的输入；创作工作台显示画面、版本及修改结果。不能为接通入口，把所有工作流强行套成固定三节点或强制 Gate。

项目关联、特效/素材/参考片引用、进入工作台及产物预览，实施前分别核对已有真实数据和接口。可直接接的接通；需新增后端契约的独立列项，不能仅靠按钮宣称已完成。

## 实施与验收顺序

1. 确定本方案方向，完成首页和新建页；用空列表、长名称、无产物、已有运行等真实状态验证。
2. 重做编辑器外壳、节点与检查器；验证原有拖动、连线、配置、撤销重做、布局、保存行为。
3. 核对项目、资源、运行与结果入口，接通已有能力，单列需要新增后端支持的部分。
4. 在亮暗主题、常用及窄窗口、较复杂节点图下验证可读性、键盘操作、拖动缩放与执行反馈。

每批展示真实截图与已验证范围。构建通过不等于交互、性能或完整执行验收通过。本文件不将拟议功能标为已完成，也不替代旧文档中尚未实现的契约。

## 2026-11-17 实施与交付记录

状态：本轮工作流首页、新建页与 React Flow 编辑器界面改版已实现；下列验证范围以记录为准，不代表通用工作流执行器已完成。

### 已落地

- 首页移除装饰横幅、序号与随机彩色封面，改用已保存节点/连线生成静态 SVG；保留搜索、最近使用、排序、复制、删除和明确空状态。
- 新建支持空白工作流与可用预设，选择后直达画布；规划中题材不再占据主要区域。
- 编辑器统一顶栏、画布工具、节点、端口、构建栏、检查器和执行抽屉。支持节点库拖入与点击添加；项目关联可选择、保存、解除；可进入关联项目工作台。
- 窄窗口选中节点时收起构建栏，配置在右侧覆层；关闭配置后可以重新展开构建栏。定向聚焦放到显式侧栏导航/添加动作，不在拖端口时自动移动视图。
- 运行前检查空图、空需求、缺输入、失效端口、重复输入与循环，并定位问题节点。分阶段评估不要求尚缺的产物先存在。
- 制作节点按项目关联显示能力；真实产物可使用保存的真实文件地址预览。下载区分实际视频与 JSON 快照，修正原来 JSON 内容被当作 mp4 下载的问题。
- 整理改为确定性布局，不在 React 重复调用状态更新器时累加行号。旧生成的分阶段布局升级为适配新卡片的尺寸，仅匹配未改动的旧默认几何；用户移动过节点/泳道的图不自动迁移。
- 保存失败保留未保存状态并提示，不再静默吞掉浏览器存储错误。
- 静态列表不挂载交互画布；节点组件 memo，节点投影缓存；去掉运行时所有连线一起播放动画，拖动节点不绘制阴影。未做 FPS/CPU 前后对照基准，不承诺定量性能收益。
