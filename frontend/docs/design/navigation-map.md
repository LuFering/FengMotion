# 导航地图（navigation-map）

> 导航已落地（2026-10-16，`src/shell/views.ts`）：扁平 6 项 + 设置居底。
> 「开始创作」按作者决定命名为**首页**，首页内容不变。

## 一、全局导航（侧栏）

```
首页          起活儿：创作想法输入、镜头库、动效来源、视频类型
我的创作      视频任务列表：正在制作 / 等待处理 / 已完成；点任务进入制作
工作流        制作方案：浏览、复制、编辑、测试工作流（怎么做）
特效库        实现方法：特效/镜头设计/转场/动画技法（用什么做）
参考片库      创作依据：参考视频、镜头拆解、风格分析（照着谁做）
我的素材      普通素材：图片/视频/音频/字体/模板/生成文件（有什么文件）
────────────────────────────
设置          侧栏底部（Agent Harness 等）
```

原则：**工作流、特效库、参考片库是核心产品能力；我的素材是基础设施。**
纠错记录不占一级入口，嵌入 AI 执行过程与工作流调试。

## 二、层级与进入关系

```
首页 ────────────── 独立（想法 → 新建任务）
我的创作 ──┬─ 任务列表（全部项目）
           └─ 点开任务 → 项目指挥中心（任务 hub）
                ├─ 制作工作台（分镜/监看/AI 对话）
                ├─ 内容编排（脚本与口播）
                ├─ 时序校验（脚本 vs 成片）
                └─ 发布与验收（交付检查）
工作流 ──────────── 独立（列表 → 编辑器 → 执行调试）
特效库 ──────────── 独立（检索 → 技法详情 → 测试/加入工作流）
参考片库 ────────── 独立（检索 → 镜头详情 → 引用到任务）
我的素材 ────────── 独立（导入 → 整理 → 供任务/工作流选择）
```

**项目内子视图（编排/时序/交付）不占全局导航** —— 从「我的创作」进入任务后切换；
这避免了「全局导航越来越长、每个页面重复挂项目状态」的老问题。

## 四、数据模型边界（与导航对应）

- **工作流定义**（工作流模块）：可长期保存、复制、编辑、复用的制作方案。
- **创作任务**（我的创作）：某次具体制作，记录当时使用的**工作流版本**、
  输入、执行过程与产出 —— 修改工作流**不得**悄悄改变已运行任务的定义。
- **知识条目**（特效库/参考片库）：带稳定 ID，可被工作流节点检索与引用。
- **文件素材**（我的素材）：文件实体 + 引用位置，与知识条目分开存储。
