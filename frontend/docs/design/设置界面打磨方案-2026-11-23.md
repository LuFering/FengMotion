# 设置界面打磨方案 · 2026-11-23

状态：本轮实施依据。适用 `frontend/src/features/settings/`。配套契约见 [设置界面契约](../contracts/settings-ui.md)；能力语义以 [settings.md](../contracts/settings.md) 为准。上一轮记录见 `docs/ui-review/settings-polish/README.md`（2026-10-29）。

## 1. 设置是什么

- **工作区级的个人偏好**，不分项目；大窗弹窗，八分类：通用 / 外观 / AI 与模型 / 创作与预览 / 插件 / 实验室 / 数据与存储 / 关于与反馈。
- 铁律：**没有消费方的不放控件**；能力能不能用只看 `/capabilities`；未接入写一句人话原因。
- 实情：契约里的 `GET/PATCH /settings` 后端没有实现（404），设置全部存在本机 `localStorage`（`fengmotion:settings`）。
- 上一轮（10-29）已定：分区不画大标题、分组之间只用一条浅线、主题样片保持自身配色。本轮沿用。

## 2. 现状问题（1440×900 深色实测）

| 位置 | 问题 | 原因 |
|---|---|---|
| AI 与模型 | DeepSeek 标「默认」，模型按钮却写「选择模型」 | 保存的 `deepseek-chat` 不在引擎实际返回的 7 个模型里，按钮找不到就退回占位文字，用户看不出问题 |
| 全局 | 快捷键键帽与区域名、主题副标、壁纸名、「设为默认」、待接入标签为 9–10px | 精调时把次要信息压得过小 |
| 弹窗 | 背后整页模糊 | 共享 Dialog 默认遮罩 |
| 打开时 | 焦点落在「查找设置分类」，搜索框带高亮框 | Radix 自动聚焦第一个可聚焦元素 |
| 外观 | 「主题」没有小标题，下方「壁纸」「界面」都有 | 主题网格没放进分组 |
| 导航 | 创作与预览 / 插件 / 实验室三栏点进去都只有「尚未接入」 | 与可用分区混排，看不出区别 |
| 数据与存储 | 「恢复默认设置」用浏览器原生 `window.confirm`；旁边「清空旧素材索引」用页内确认 | 两种确认方式不一致 |

## 3. 改动

1. **模型按钮如实**：当前引擎的已保存模型在列表里→显示其名称；不在列表里→显示「deepseek-chat · 不在列表中」并以警示色标出，提示重新选择。**不自动改写用户设置**。
2. **最小字号 11px**（键帽、区域名、主题副标、壁纸名、默认标记、引擎状态）；待接入小标签 10.5px。
3. **轻遮罩**：与特效库详情同值，不模糊。
4. **打开时焦点落在当前分区的导航项**，不抢到搜索框。
5. **外观**：主题网格加「主题」小标题，与壁纸、界面同一分组语法。
6. **导航分两段**：可用分区在上；创作与预览、插件、实验室归到「尚未接入」小标签下，弱化显示。未接入页各补一句原因。
7. **恢复默认设置**改为页内确认（与清空旧索引一致）。

## 4. 不做

- 不新增 `/settings` 后端；不改设置字段与存储键。
- 不删分类（八分类来自规划文档）。

## 5. 验收

- 1440×900、860×680；深色 / 浅色 / 纸感。
- DeepSeek 卡片不再显示「选择模型」占位；面板最小字号 ≥ 10.5px。
- 打开设置时焦点在当前导航项；遮罩不模糊。
- 恢复默认需页内二次确认；取消后设置不变。
