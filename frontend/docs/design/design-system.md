# 统一设计系统（design-system）

> **本文件是约束，不是建议。** 新页面只允许使用这里定义的 token、字阶与共享控件。
> 2026-11-24 按《前端全面打磨方案-2026-11-23》§2 改写；旧版的颜色取值表、15/16px 视图标题、999px 胶囊圆角等已作废。
> 参考产品（React Flow / Dify / ShotDeck 等）的皮肤**一律不要**，只借结构与交互。

## 〇、样式从哪里来

| 层 | 文件 | 说明 |
|---|---|---|
| 入口与顺序 | `src/index.css` | 全局样式的引入顺序，改顺序前先读它 |
| 底座 | `styles/paba/app-slim.css` | 旧底座，只读，不再往里加规则 |
| 品牌 | `styles/brand.css` | 首页「纸」层等品牌覆盖 |
| 尺度 token | `styles/tokens.css` | 字阶、圆角、间距、动效（`--fm-*`） |
| 颜色 token 与旧名别名 | `styles/theme-v3.css` | 页面层颜色，按 `html[data-theme]` 定义**一次**（深色 / 浅色 / 触感）；`--r-ctl`、`--eo` 等旧名也在这里指向 `--fm-*` |
| 共享组件 | `styles/fm-components.css`、`styles/fm-page.css`、`shared/components/*` | 下文第四节 |
| 页面 | `features/<页>/styles/*` | 只调本页布局；页头与字阶收口在各页 `page-chrome.css` |

不再有跨页补丁文件：原 `styles/interface-polish.css` 已于 2026-11-24 按页拆回 `features/*/styles/*page-chrome.css`，只搬家、不改值。新规则写进所属页面的文件，不要再建「全局打磨层」。

## 一、颜色

- **唯一来源**是 `styles/theme-v3.css`：`--tx / --tx2 / --tx3`（文字三档）、`--panel / --panel2 / --raised`（表面）、`--line / --line2`（分隔）、`--hover`、`--acc / --acc-ink` 等。页面文件里**不得**重新定义这些变量，也不得写死十六进制颜色。
- 新增颜色先加进 `theme-v3.css`，并给三套主题都赋值。
- **状态色只表状态**：`--ok` 完成、`--warn` 等待你决定（不是失败）、`--bad` 失败。装饰一律用 `--acc` 或中性灰。状态的标签与圆点走 `shared/lib/status.ts`（`statusOf()`）+ `.fm-dot[data-s]` / `.fm-tag[data-s]`，组件里不自己写状态色。
- 状态**不能只靠颜色表达**：圆点 / 色块旁必须有文字。
- **画面上的控件**（海报卡角按钮、影院浮层、播放条）固定深色玻璃 + 白字，三主题一致。
- 第三方嵌入组件（如 LeiBox 输入框）不写死颜色：宿主通过 `--lbx-*` 传入，浅色分支也要传。
- 深色主题必须保持 `color-scheme: dark`（否则系统滚动条变白）。

## 二、字阶

定义在 `styles/tokens.css`：

| token | 值 | 用途 |
|---|---|---|
| `--fm-text-page` | 25 / 550 | 库级页面标题（特效库、素材、工作流） |
| `--fm-text-view` | 15 / 600 | 面板、详情、弹窗标题 |
| `--fm-text-body` | 13 / 400 | 正文、名称 |
| `--fm-text-sub` | 12 / 400 | 次要正文、列表值 |
| `--fm-text-meta` | 11 / 400 | 元数据、时间码、计数 |
| `--fm-text-mini` | 10.5 / 500 | **下限**：铭牌、角标、刻度、键帽 |

- 不低于 10.5px；9 / 9.5 / 10px 是存量，改到哪页顺手升档，不新增。11.5、12.5、13.5 这类非档位值同样不新增。
- 数字用 `font-variant-numeric: tabular-nums`，**不用等宽字体**；等宽只给代码与文件路径。
- 衬线字体只用于首页品牌标题。
- 层级必须拉开：标题比正文醒目，正文不用 14px 以上。

## 三、圆角、间距、动效、焦点

- **圆角四档**：标签 4（`--fm-radius-mark`）· 控件 6（`--fm-radius-ctl`）· 卡片 10（`--fm-radius-card`）· 面板 14（`--fm-radius-panel`，触感主题 20）。胶囊 `--fm-radius-pill` 只给确实是胶囊的元素。旧名 `--r-ctl / --r-card / --r-panel` 是指向新档的别名，新代码用新名。
- 间距：面板内边距 12–16px；区块间距 16–24px；库级页面标题左缘距导航栏 32px。
- 动效：缓动用 `--fm-ease`（旧名 `--eo` 为别名）。颜色、透明度过渡 .15s，面板 .22s。不加上浮、发光。尊重 `prefers-reduced-motion`。
- 焦点环：`2px solid var(--acc)`，偏移 2px，只在 `:focus-visible`。

## 四、共享控件（每类只一个实现）

| 控件 | 实现 | 规则 |
|---|---|---|
| 单选下拉 | `shared/components/MenuSelect`（基于共享 `DropdownMenu`） | 不再用原生 `<select>` |
| 弹窗 | `shared/ui/dialog`（`DialogContent` 等） | 遮罩 `rgba(5,5,8,.52)`、不模糊背后页面；Esc / 点遮罩关闭；关闭键读屏「关闭」 |
| 提示 | 共享 `toast` | 可撤销的操作带撤销：`toast(text, { action: { label: '撤销', run } })`，撤销只撤这一次的变化 |
| 播放条 | `shared/components/MediaTransport` | 播放、细线进度（悬停时间气泡）、时间读数、静音；替代浏览器原生 `controls` |
| 时间格式 | `shared/lib/time.ts` 的 `formatClock` | 见第五节 |
| 空 / 读取中 / 失败 | `EmptyState`（可带主动作 + 次动作）/ `LoadingState` / `ErrorState` | 读取中骨架与真实卡片同尺寸；读取失败是独立状态，不显示成空库 |
| 状态 | `.fm-dot[data-s]`、`.fm-tag[data-s]` | 见第一节 |
| 搜索框 | `.fm-searchfield` | 快捷键键帽 10.5px |

复用组件 ≠ 复用布局：三库共用控件与交互，**不共用页面模板与数据模型**（见 `knowledge-library-spec.md`）。

## 五、时间码

- 不出现 `00:30:00` 这种「分:秒:帧」写法（会读成 30 分钟）。
- 播放读数写 `0:03.4 / 0:30`；时长写「4 秒」。
- 需要帧精度的地方（工作台时间线悬停、场景编辑器入出点）在数值旁写「第 102 帧」。
- 同一页的总时长只取一个来源。

## 六、页面骨架（三种形态，按任务选）

1. **壳层页**（我的创作 / 工作流 / 特效库 / 参考片库 / 我的素材）：侧栏 68px 图标轨，可展开；内容区按现有约束。参考片库是影院形态：画面铺满，播放时只淡出导航，控件不随导航显隐横移，始终留在侧栏安全区内。
2. **工作台类**（制作工作台 / 编辑器）：全幅、多栏、面板化，不套卡片 Dashboard。
3. **复刻页**（项目指挥中心 / 时序校验）：iframe 全区装载（`.acr` / `.atr`），与壳层无缝（满幅、无白边、无内滚）。

## 七、状态与反馈

- 加载 / 成功 / 警告 / 失败 / 禁用：用 `status.ts` 五键加文字，不造第六种。
- 后端未实现的能力：**灰显 + 注明原因**（沿用「未接入」模式）；演示交互必须明确标注，不得伪装成真实执行。
- 异步操作必须有进行中态与失败态。

## 八、视觉气质

专业创作软件：信息密度适中、操作明确、视觉内容突出、画布空间充足。
**禁止**：所有页面同一种卡片 Dashboard；滥用渐变、发光、大面积装饰；装饰性阴影；统计数字大卡。
