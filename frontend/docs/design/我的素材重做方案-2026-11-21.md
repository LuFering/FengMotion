# 我的素材重做方案 · 2026-11-21

状态：本轮实施依据；视觉效果待用户验收。适用 React 主前端 `frontend/`，不改历史 Vue 副本。

## 定义与用途

我的素材是工作区级真实文件库：图片、视频、音频、字体、文档，包含用户导入、内置文件和生成结果。项目通过引用关系使用它；加入待发送只是创作输入暂存，不等于发给 AI，也不新增项目引用。视频登记为参考片是另一项显式动作，不宣称已经分析。

主要任务：导入 → 找到 → 预览 → 加入待发送。次要任务：收藏、文件夹、标签、改名、查看引用与授权、管理审核。依据 `PRODUCT.md`、页面职责合同、当前 Assets/assetApiService/AssetController，而非历史截图中的演示数据。

## 现状与工作台经验

已运行当前页面，前图在 `../ui-review/assets-redesign/before-dark-1440.png`。真实本机库有三项素材。现有顶栏承载全部工具，内容缺少所在分类；文件名压在图片上、图片被放大裁切；左栏状态项多于文件组织项；详情操作过密，空库和导入失败反馈薄弱。此前修改的批量更新、文件夹 CRUD、参考片登记等真实接口继续接通。

工作台可复用的是层级与职责：画面先于参数、工具按作用范围摆放、详情按需出现、主操作唯一、灰阶和间距代替叠框、窄窗口主动收起面板。不能把工作台三栏原样复制为素材页的常驻布局。

## 设计决定

采用 Operate 模式：紧凑的素材浏览器。沿用当前工作台的冷灰、蓝色操作信号与系统中文字体，不新建全站品牌。

1. 页头：我的素材、名称/标签/授权说明搜索、导入。标题 20px，搜索和主按钮 36px。
2. 左栏约 208px：全部、收藏、最近使用；文件夹在第二组；来源、引用项目、标签、授权与审核可折叠。分组标签是中性文字。计数来自真实库。
3. 浏览区：范围标题和数量、排序与网格/列表；第二行是全部/图片/视频/音频/字体/文档的直接筛选，以及批量选择。计数随范围和搜索变化，尚未应用类型筛选。
4. 卡片：16:10 预览与独立文字区。图片 contain，透明区域用中性棋盘底，不人为增亮/裁切；视频静帧与悬停静音预览；字体加载真实字样，失败有标记；音频/文档清楚标明类型，不伪造波形。名称 13px、元信息 12px、卡间距 18px。弱边框、状态变化，取消卡片悬浮位移。
5. 卡片控件：选择框、收藏、加入待发送；鼠标悬停与键盘聚焦都可见，已收藏/已加入保持可辨。处理失败、停用、演示等必要状态直接表达。
6. 详情：预览与加入待发送在上；文件属性、标签和引用在下；授权与审核独立折叠区域。删除保留确认，引用保护由服务器最终裁定。
7. 批量操作条限定在页面内，可换行；移动、标签、收藏、导出清单、删除和加入待发送继续可用。筛选变化保留选择，数量明确是所有已选项。
8. 导入：紧凑行内进度（文件序号/总数，无虚构百分比）、实际错误与重试。当前文件夹作为上传目标；按 ID 合并返回值，避免重复卡片。尊重此前删除大型导入队列与全屏拖拽提示的决定。
9. 浏览详情不再写“最近使用”；这不等于素材投入创作。最近使用仅展示已有真实字段。
10. 窄窗口默认收起组织栏；详情窄屏使用可关闭抽屉，焦点与 Escape 行为明确；内容保持可滚动，操作条不盖住最后一行。

## 验证

真实库前后同尺寸截图；另以仅浏览器拦截的明确演示夹具覆盖多媒体、长名称、停用/失败、空态和大量条目。浏览器检查搜索、范围计数、类型、排序、详情、文件夹、批量操作、导入重试、重复去重及键盘。构建/lint/相关契约测试；界面成功与用户视觉认可分开记录。

## 本轮落地的视觉参数

局部作用域 `.mya-library`：暗面继承 #16171d、正文 #edeef3、次文字 #a4a7b1；选中与焦点蓝 #3B8CF8，白字实心按钮另用 #2465cc（hover #205bb9）。浅色与 tactile 继续继承页面主题。页边距24px、面板间距16px、分类208px、详情320px；面板/卡片/控件圆角14/10/7px；标题20px、范围标题15px、名称/操作13px、元信息12px。768px以下搜索独占一行，1200px以下详情用原生 dialog。只记录本页面策略，不重写其他页面设计系统。
