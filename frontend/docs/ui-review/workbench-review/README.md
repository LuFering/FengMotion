# 工作台功能与界面改造记录

日期：2026-10-29。此记录为开发自检，不代表用户验收通过。

## 依据与用户视角

已阅读《FengMotion产品体验与工作流说明.md》及项目的前端开发规范、设计原则、页面职责合同。工作台应帮助用户看真实结果、指出修改位置、说明保留内容，再核对执行情况。无画面是正常制作状态；测试帧、试片和整片不是强制审批阶梯。

原界面在没有本次视频时仍使用旧场景标题、旧片时长和看片待决定；引用依赖静态场景而非当前播放媒体；执行入口和固定生成历史无法准确说明本次制作。此次优先修复这些功能问题，并重组空态、目标信息、意见输入和记录展示。

## 已实现

- 无预览时展示原始创作需求、补充要求入口与真实执行状态，不默认展示旧场景或旧片时长。
- 预览根据当前项目运行产物解析；优先最新有画面的运行，同次运行内按画面档位排序。历史只列真实存在的预览来源。
- 原生视频引用按当前播放秒数记录；框选基于媒体实际显示区域，排除 contain 留白。引用保留项目、文件、运行、产物和工作流版本。
- 参考素材带入对话时作为上下文，不能冒充待修改成片。目标和上下文分别呈现。
- 修改意见发送时捕获目标、时间、区域和保留条件快照；之后改变输入区设置不会改变已发送记录。快捷提示只填写草稿。
- 当前目标面板显示实际来源；项目切换隔离新消息与请求队列。排队请求按项目保存在 sessionStorage。
- 执行抽屉接入项目工作流真实日志与产物；演示执行结束不会宣称视频已生成。有预览的审阅决定绑定实际版本，并拦截不具备条件的确认。
- 调整三栏宽度、需求准备区、素材缩略标签、输入区、目标详情、请求快照和记录抽屉；采用现有主题变量。

## 当前边界

Agent 与渲染仍未接通，本次不具备真实视频生成、真实文件修改及自动前后对比能力。意见与对话任务为演示会话记录，不是服务端持久化系统；队列仅在当前浏览器会话按项目保留。未声称完成移动端、所有异常分支或所有旧调试入口验证。保留了其他开发者已有改动，未提交或覆盖其工作。

## Remotion 入口恢复

工作台顶栏恢复常驻文字按钮“Remotion 编辑器”。点击后保持在工作台，中间展示已有 Remotion Player，右侧展示已有参数面板；收起右栏后再次进入也会自动打开参数面板。编辑模式提供场景模板切换和退出入口，深链 edit=1 / panel=edit 同步显示编辑预览与参数。

当前仍为现有场景模板参数编辑能力，未接通生成项目 composition 或成片重新渲染；界面明确说明本机参数不覆盖已有视频。移除编辑状态下误导的成片引用操作，避免引用错误来源。

浏览器验证：入口打开、改标题并应用、刷新后保留、恢复原参数、切换场景模板、退出、右栏收起后重新进入均通过。测试标题已恢复。构建通过，所改工作台文件检查通过；RemotionEditPanel 存在原有 set-state-in-effect 提示。截图 remotion-editor.jpg 为实际 4173 页面。
