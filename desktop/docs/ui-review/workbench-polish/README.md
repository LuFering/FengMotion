# 工作台 UI 重整 · 2026-10-29

状态：已实现，待用户审美和交互验收。没有将本轮截图标为已确认设计。

## 设计调整

- 顶栏减去永久禁用的撤销/重做，突出项目、制作审阅、场景编辑器和实际交付；用 Film 图标代替无语义的 W。
- 左侧改为项目空间，压低演示执行的视觉重量，保留原待决定牌堆、内容/资料导航。底部提供制作要求与编辑器入口。
- 中央预览使用稳定边界和更明确的留白。没有预览时展示真实状态与编辑入口，简报移到下方，正文限制行数并保留完整要求入口。未伪造预览。
- 右侧提供连贯的创作助手区域，减少重复项目名和作用范围，完善输入区焦点与禁用态；保留引用芯片、意见记录和真实范围。
- 新增“专注画面”按钮，收起/恢复右侧工作区；小窗口初始收起对话，避免浮层挡住画布。
- 素材预览增加加载失败与手动重试，避免裸露破图；实际路径继续复用素材服务。
- 新样式只作用于 `.wb-a2.wb-studio`，复用当前主题 token，未重绘全局导航、首页或素材库。
