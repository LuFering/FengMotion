# 更新日志

本页记录 FengMotion 面向版本的变更：新增、变更、修复、移除与升级注意事项。只记用户可感知的变化与对协作有影响的工程事项；实现细节查 git 历史。

维护规则：

- 顶部保留「未发布」段，随 PR 合入时把变更归入该段；发布时改段名为版本号与日期。
- 同一版本内同一功能的后续修复，直接修订原条目，不重复新增。
- 条目优先写用户影响与操作变化，其次才是实现方式。
- 本日志自 2026-10-22 建立；建立前的历史以「基线」段概括，不逐条追溯。

## 基线（2026-10-22 建立时点的仓库状态）

- 视图收敛为 8 个：首页、我的创作、工作流、特效库、参考片库、我的素材、制作工作台、发布与验收。此前一輪清理删除了资源接入、反馈与规则、内容编排、时序校验等整页与 3 个孤儿视图、历史备份文件，共净删约 1.95 万行。

- Agent 后端未接入：前端全部任务状态来自演示适配器，UI 已按口径标注演示。


## 2026-10-29 · 本机场景编辑器重构（待用户验收）

- 工作台内提供源场景选择、画布、局部滚动的属性面板和图层/时间范围列表，移除固定七项参数的标题覆盖实现。
- Token 项目绑定 30 个实际 HTML + GSAP 源快照；真实文本/图片与布局覆盖、动画时间重映射、来源追溯和工程包导出。
- Remotion 原生场景支持文字、图片、视频、声音、形状；支持拖动位置、层级、时间、动效、素材绑定、本机保存和撤销/重做。
