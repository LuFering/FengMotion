# 文本提取 · 提示词 / 字幕

## 从提示词提取

| 字段 | 问什么 |
|---|---|
| 意图 | 这条片要让观众知道/相信/感受到什么？ |
| 画幅 | 时长、fps、宽高、平台 |
| 内容 | 事实、数字、来源、必须出现的句子 |
| 视觉指令 | 用户明确说的机制/镜头/色板/材质/禁忌 |
| 音频 | BPM、有无配音、同步点 |
| 边界 | “不要 PPT / 不要大字卡 / 不要照片推拉” |

> 用户说了的，逐字保留；用户没说的，不要补成“电影感”。

## 从字幕/旁白提取

| 字段 | 问什么 |
|---|---|
| 事实 | 有没有数字、结论、时间、人名、来源？ |
| 论证 | 这段话在证明什么？ |
| 情绪 | 克制 / 热血 / 温柔 / 压迫 / 反问 |
| 拍子 | 3–5 个“观众多知道了什么”的转折 |
| 语速 | 字数 / 时长，估算 BPM 或留白 |

**不要提取**：镜头、色板、构图、转场。字幕里没有这些。

## 输出

写进 `content.facts` / `content.beats` / `content.tone`；
视觉字段留给图片/视频/提示词，或标成 `needs_decision`。
