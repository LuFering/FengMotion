# G3 · Animatic

> 这是制作层最重要的一步。时间在这里才出现。

## 做什么

1. 用占位/粗动画把整个片跑一遍：480×270、12fps、真实音乐或 VO。
2. 不追求好看；追求“事件顺序、载体、节奏”成立。
3. 量每一段**实际需要多久**，写进 `timing.sections[].seconds`。
4. 只保证 `brief.timing.hardAnchors` 命中；软目标可以移动。

## 时间不够/太多怎么办

- 某段需要更久：砍内容、合并 beat、换更简单的载体。
- 某段太快：不要加空镜/慢推/无意义停留；先问“这一拍是不是本来就没内容”。
- 总时长超了：先删 beat，不要压缩到读不清。
- 总时长不够：不要拉长镜头；加一个真正有信息的事件。

## 自检

- 关掉声音看一遍：画面还成立吗？
- 只看 1/4 速度：运动连续吗？
- 只看每段第一帧和最后一帧：能看出变化吗？
- 有没有一段只是为了“对到某个秒数”而存在？

## 输出

```json
"timing": {
  "status": "measured",
  "hardAnchors": [{ "at": 0, "what": "..." }],
  "sections": [
    { "name": "...", "seconds": 2.0, "why": "..." }
  ],
  "totalSeconds": 25,
  "paddingCheck": "每一段都有事件；没有为对齐秒数加空镜/慢推。"
}
```

`status` 从 `plan` 改成 `measured` 之前，不要写最终 scene 代码。
