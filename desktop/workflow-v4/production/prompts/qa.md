# G5 · QA

> 自动检查负责“没坏”，视觉审片负责“好不好”。

## 必查

### Stills

- 每个 beat 至少 2 帧；
- 关键转场拼 contact sheet；
- 每帧看：主体在不在、文字读不读得清、色板对不对、有没有空。

### Motion

- 每段渲 2–3s 低分辨率片段；
- 看运动连续性、速度变化、转场、数据可读；
- 不要只看单帧；单帧好看不代表运动成立。

### Audio

- 时长、响度、声道、音画同步；
- 有没有爆音/静音/尾帧被切；
- 音频在 G3 就定，不要最后才改 gain。

### Data

- 每个数字对 `source`；
- 指标、单位、双方标签是否一致；
- 单侧数据（如榜单）有没有用位次/密度表达。

## 输出

```json
"qa": {
  "frames": ["out/qa/f0.8.png", "out/qa/f10.6.png"],
  "motionClips": ["out/qa/clip-ascent.mp4"],
  "issues": ["结尾 3.25s 偏紧，已把提问句改成倒序擦除"],
  "acceptance": ["...每条对 brief.acceptance..."]
}
```

## 二值验收

- 每条 acceptance 只有“成立/不成立”，没有“部分成立”。
- 关掉声音看一遍：字幕里提到的磨豆机、门、人、窗，画面里是否真的出现？没有 = 不成立。
- 如果一条不成立：改 brief/载体/beat，不要把“部分成立”写成通过。

## 门 5

- `brief.acceptance` 每条成立；
- 没有黑帧/死帧/文字读不清/爆音；
- 每个 beat 至少有一帧能证明它成立；
- 如果某条不成立，退回 G2 或 G3，不要用字幕解释。
