# Quality Bar / 看片问题

> 这不是 pass/fail 门禁，也不是审美打分器。
> 它是一组看片时用来定位问题的问题：哪里像目标、哪里最 generic、下一轮只改什么。
> 技术底线单独列在最后；技术通过不等于画面成立。

## 0. 默认验证策略

> 先验证设计编码，再验证画面；抽帧不是默认创作方式。

- 先检查 tokens/grid/type/frame score/invariants：能在代码里推理的，不靠大量看图。
- 渲染只验证不可计算项：材质/光/合成/遮挡/文字实际落位；先写 2–4 个视觉假设，再决定看哪几张帧。
- 连续预览只用于运动/节奏/切点；没有就记录“未做连续播放审片”，不用抽帧冒充。
- 抽帧是定位工具，不是创作方法；截图数量不等于设计质量。
- 代码级不变量：主体/文字在安全区，关键动作有可见窗口，状态连续，时间边界在帧内。

### 0.1 Finishing Pass（首版后整体审片）

首版完整渲染后，不要直接收尾。先按**观众第一次观看**排序：

1. **观看动机**：开场有没有继续看的理由？主题是否快速可读？
2. **宏观结构**：有没有重复构图、空段、无意义留白？场景类型是否足够不同？
3. **信息与节奏**：核心数据读得完吗？高潮有没有足够时间和视觉响应？
4. **收束**：结尾是否完成表达，而不是逐渐变暗/对象停住？
5. **局部精修**：材质、线条、光效、微小图形。

- 看完能否复述核心观点/关键变化/结论？与内容契约对照；相邻镜头是否只是换了标签/图形？高潮是否明显强于过渡段？结尾是否回应开场？
- 只选一个**质量瓶颈**；一个瓶颈可以包含多个协同修改（字号+停留+对比+层级），不是只能改一个属性。
- 有播放条件：首版和最终版各完整播放一次；没有就用 2–3 秒短运动预览 + 高帧率时间序列 + 人审，明确记录“未完整连续审片”。
- 2fps 接触表只能定位大致画面，不能代替完整动态审片。
- 尽量局部重渲；最终整体回看一次。
- 静帧假设不能代替整体审片。
- 可选：可借 video-shotcraft 的 aesthetic-rules/final-review、lemo-opuscar 的 DIRECTOR.md 作为补充问题；不替代本清单和 Finishing Pass。

### 0.2 外部 critic（推荐，不是门禁）

- 找 fresh agent 或人只看 8–12 张关键帧/1fps 接触表；
- 问：哪几帧像同一个模板？哪一段最空/最不想看？哪里不像高潮？结尾是否回应开场？
- 记录外部意见；不要只用生成模型自评。

### 0.3 观众理解测试（首版后）

找一个没看过创作方案的人**完整观看**首版，不提前告诉他应该理解什么。只问：

1. 这条视频主要讲了什么？
2. 最关键的变化/重点是什么？
3. 哪一段没看懂，或者觉得拖？
4. 最后留下了什么结论/印象？

把回答和 `lookdev-brief` 的内容契约对照：

- 说错了 → 内容顺序/视觉证据问题；
- 漏了重点 → 重点不突出/停留不足；
- 说不出结论 → 镜头再漂亮也没有完成叙述。

没有真人/完整播放条件时，用外部 critic + 1fps 序列作代理，并明确写“不是完整观众测试”。

### 0.4 理解测试 → 返工决策

| 观众表现 | 优先修什么 |
|---|---|
| 说不清主要讲什么 | 叙事顺序 / 视觉证据 / 内容契约 |
| 知道主题，但说不出关键突破 | 重点镜头的差异 / 停留 / 视觉语义 |
| 能复述事实，但看不出关系 | 阶段因果 / 镜头衔接 |
| 理解完整，但觉得平淡 | 节奏层级 / 高潮 / 结尾汇聚 |
| 只记住最后一个图形 | 结尾没有从前面机制推导，补汇聚过程 |

不要用“再加光效/粒子”掩盖理解问题。

## 1. 第一眼

- 全片的视觉机制是什么？每个镜头是否服务它？
- 观众第一眼看到什么？这个焦点是主动选择的吗？
- 画面有没有一个视觉命题，而不是只有“氛围”？
- 有没有一帧值得暂停、截图、记住？是哪一帧？
- 核心视觉事件是什么？观众能一眼读出来吗？
- 每个镜头是否改变了“我在看什么”？还是只是换了一个物体？
- 如果把字幕拿掉，第一眼还能看懂在发生什么吗？

## 2. 画面

- 构图：焦点/留白/前后景/视觉动线是否成立？还是所有东西平均用力？
- 光：方向、软硬、衰减、受光面、接触阴影是否清楚？暗部有层次还是死黑？
- 材质：背景/台面/主体/道具是否能区分？有没有“所有东西同一种塑料感”？
- 色版：颜色有角色分工，还是单一棕色/灰色糊成一片？
- 镜头：景别/机位/景深是否服务内容？还是所有镜头同一机位？
- 细节：哪些细节让画面可信？哪些细节只是装饰？
- 景别：主体占画面多大？整体/中景/细节/极特写？为什么是这个距离？
- 视点/机位：正面/斜俯/俯视/沿轴推进/进入空间内部？所有段落是否都在同一个观看位置？
- 空间层次：前景/中景/背景是否有视差、尺度或焦点差异？还是全部贴在同一平面？
- 镜头衔接：切点是形状匹配/动作接续/视线转移/尺度突变/光位/声音，还是只是上一段结束？
- 镜头关系：前一个镜头的运动/状态是否自然引出后一个？还是只是“上一段结束、下一段开始”？
- 视觉因果：版本/数据/图形变化是否有明确语义，而不只是换标签/换形状？
- 镜头落地：计划中的景别/视点/空间层次/衔接，在代码/成片里是否真的出现？有没有只是放大/换字/硬切？
- 视觉密度：主体层级/前中后景是否成立？信息层/刻度/标注是否承担功能？留白是否服务节奏/对比？
- 镜头差异：这一镜与上一镜在空间/视角/构图/信息布局上，是否至少有一项真正改变？

## 3. 运动

- 运动是由事件驱动，还是为了“有动效”而漂移/缩放？
- 关键动作有没有 start → middle → end，还是只出现对象？
- 中间态是否可信？有没有突然跳变？
- 静止是有意停顿，还是动作没做完？
- 动作的路径/速度/停顿有设计吗？还是匀速插值？
- 动作是否有表现力：事件发生 → 清楚可信 → 有重点/节奏，而不只是“完成任务”？
- 关键动作的预备/触发/接触/反应/停顿，哪一拍最值得看？
- 光/阴影/液体/粒子/材质是否对动作作出反应？
- 镜头运动有理由吗？速度/停顿/跟谁？还是在掩盖构图问题？
- 切点是否继承动作/状态，还是跳变？
- 这些问题只能用连续画面判断；如果只看静帧/接触表，要明确记录“未做连续播放审片”。

## 4. 叙事与字幕

- 画面本身能说明事件/因果吗？还是主要靠字幕解释？
- 字幕/旁白是否在复述画面？如果是，删掉或改画面。
- 每个镜头是否有“只有画面才能说”的东西？
- 事件之间是自然衔接，还是每段换一张图？
- 去掉字幕看一遍，事件链还成立吗？
- 原文/用户要求的事件都在吗？哪些被删/背景化？有没有替代呈现？

## 5. 结尾

- 最后一个动作完成了吗？还是对象被“放”到画面上？
- 结尾和开场有呼应吗？是空间/光/构图/声音的呼应，还是只是同一个背景？
- 最后几秒是收束，还是停滞？
- 全片有视觉高潮吗？哪一个瞬间是重点？
- 观众最后带走的是什么画面/情绪？

## 6. 常见失败模式

- 默认暗背景 + 渐变光 + 居中大字；
- 几何占位符冒充材质；
- 每个镜头都同一构图/同一机位；
- 用粒子/发光/抖动掩盖没有事件；
- 字幕解释一切，画面只是插图；
- 动作只有首尾，没有中间态；
- 结尾对象停住，没有完成动作；
- 参考只借了颜色，没有借光/材质/构图/镜头。

## 7. 验证方式

### 7.0 假设驱动验证

- 渲染前写 2–4 个“不确定的视觉假设”，例如：折线是否在上升、星环是否成型、数据行是否重叠、释放是否有冲击。
- 渲染后只检查能回答这些假设的帧；帧数由假设决定，不固定 3–6 张，也不大批量浏览。
- 假设全部通过，仍然要做 Finishing Pass；连续预览/短运动预览不能省略。
- 不要用“我看了很多帧”代替明确假设。


- 能连续播放就连续看；连续看才能判断节奏、接触反应、切点和高潮。
- 不能连续播放时，用密集抽帧/时间序列（例如 4–6 fps 接触表 + 关键动作帧）替代，并明确写“未做连续播放审片”。
- 不要把抽帧结论冒充完整看片；不要只检查首帧和尾帧。
- 具体 finding 带时间点/帧号/观察/下一步；没有证据的判断标为“推断”。

### 7.2 镜头级定向返工

- 先定位到具体镜头/时间段，只改相关组件或区间；
- 重渲同一段对比，不要每次重写全片；
- 局部复查通过后，再决定是否全片复检；
- 找不到具体问题，就先不要重渲。

## 8. 一轮只改一个最大问题

看完一遍，按“如果只改一个，哪个提升最大”排序：

1. 视觉方向/媒介不对；
2. 构图/焦点不对；
3. 光/材质不对；
4. 镜头/运动不对；
5. 字幕/节奏不对；
6. 结尾不对。

只改第一个；改完再拍一次，不要同时改五件事。

## 9. 技术底线（这些必须过）

- 可播放、规格正确、无损坏；
- ffprobe 检查分辨率/fps/帧数/音轨/pix_fmt/color_range/color_space；
- 资源路径真实存在；
- 原文要求逐字保留的内容没有遗漏/改写；
- 没有伪造参考/素材/渲染/批准；
- `sketch`/`prototype` 明确标记非交付。
