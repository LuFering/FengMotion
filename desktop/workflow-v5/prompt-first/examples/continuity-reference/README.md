# 连续性参考实现（结构参考，不是视觉模板）

这份示例只展示**跨事件、跨镜头、状态传递**的结构，不规定题材、画风或镜头语言。

它演示：

- 事件（Event）可以跨越多个镜头；
- 镜头（Shot）是时间/观看单位，不是“一句文本一个镜头”；
- 字幕（Caption）是独立轨道，可以跨越镜头，不因字幕换行自动切镜头；
- 每个镜头显式记录 `continuityIn` / `continuityOut` 和主体状态 `stateIn/stateOut`；
- 执行层应继承上一镜状态，而不是让每个组件从默认初始状态重新开始；
- 全片应先做低保真 animatic，再进入完整视觉制作。

配套文件：

- `film-plan.md`：节奏、事件、连续性、结尾；
- `shot-plan.json`：机器可读的镜头/事件/字幕/状态交接；
- 校验：`node ../../tools/validate-shot-plan.mjs shot-plan.json`

不要把这里的对象、构图或节奏当成默认创作模板。
