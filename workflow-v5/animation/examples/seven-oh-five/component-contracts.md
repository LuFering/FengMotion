## Scene01LightReveal

- 用途：光带进入并分层揭示空间；对应 S01，源 L1。
- 接口：props 由实现阶段按分层资产确定；不硬编码色值/字体。
- 运动状态：暗空间 → 光带出现 → 光带扩大 → 空间层次稳定。
- 验收：开场空间偏暗；光带先于人物出现；结束时光仍是焦点。
- 状态：candidate（需 10s 证明）。

## Scene02Grinder

- 用途：一次磨豆机机械动作；对应 S02，源 L2。
- 接口：props 控制动作峰值与停止；不伪造不存在的素材。
- 运动状态：静止 → 启动 → 动作峰值 → 停止。
- 验收：动作前安静；有一次清楚可见的动作；动作后恢复稳定。
- 状态：candidate（需素材可行性验证）。

## Scene03Extraction

- 用途：液体流动与杯壁颜色变化；对应 S03，源 L3。
- 接口：props 控制液体进度与颜色变化；运动必须由形态/路径变化承担。
- 运动状态：干燥咖啡粉 → 水接触 → 液体汇聚 → 杯壁变深。
- 验收：能看到流动与颜色逐渐变化；不能整体缩放假装流动。
- 状态：candidate（需连续液体方案）。

## Scene04LatteArt

- 用途：白褐交汇与花朵纹路形成；对应 S04，源 L4。
- 接口：props 控制纹路扩展进度；结果状态必须可停留。
- 运动状态：无花纹 → 白色进入 → 白褐交汇 → 花朵形成并保持。
- 验收：从无到有；结束时纹路可辨认且稳定；不能直接显示完成图案。
- 状态：candidate（需形态形成方案）。

## Scene05DoorLight

- 用途：开门、外部光进入、光落杯沿；对应 S05，源 L5。
- 接口：props 控制开门进度与光的方向；保持空间连续。
- 运动状态：门关闭 → 门缝光 → 门开 → 光落杯沿。
- 验收：内外空间通过光连接；不能只加无方向扫光。
- 状态：candidate（需空间连续性验证）。

## Scene06CupPlacement

- 用途：放杯动作的开始/接触/结束与停留；对应 S06，源 L6。
- 接口：props 控制杯子路径与接触状态；结束时允许静止。
- 运动状态：杯子在吧台 → 移动 → 接触窗边 → 手离开 → 停留。
- 验收：杯子不瞬移；接触状态清楚；结束后画面停留。
- 状态：candidate（需动作与停留状态验证）。
