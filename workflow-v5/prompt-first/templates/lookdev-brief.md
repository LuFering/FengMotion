# Look-dev Brief（首帧视觉定标）

> 在写完整动画之前填完。目标不是写文档，而是避免第一版直接变成“深色背景 + 几何光 + 文字”的代码占位符。
> 静帧不过这里的质量门槛，不允许进入完整动画。

## 1. 媒介适配（先判断上限）

- `mediumFit`: `real-footage` / `generated-image` / `procedural` / `mixed`
- 用户是否允许实拍/生成素材：是 / 否 / 未说明
- 如果要求写实质感但没有素材：**先说明上限**，不要假装程序化能替代摄影。
- 这条选择会决定：继续做 sketch，还是先补素材/look-dev。

## 2. 视觉目标（一句话）

- 观众第一眼应该看到什么？
- 第二层看到什么？
- 这一帧如果暂停，应该像一张设计过的画面，而不是幻灯片。

## 3. 画面设计

- **构图**：主体位置、留白、前景/中景/背景、视觉动线。
- **光**：方向、软硬、衰减、色温、受光面、接触阴影；光从哪来、先照到什么。
- **材质**：每个大面是什么材质（墙、台面、杯、窗）；不能只靠纯色块。
- **色彩**：主色/辅色/强调色；暗部是否死黑。
- **文字**：字体、字号、字距、位置、对比、安全区；文字和画面谁是主体。
- **运动意图**：这一帧之后什么会动；不要用粒子/缩放掩盖没有事件。

## 4. 参考与证据

- 参考图/帧/链接（至少 1 个，或明确 `reference-free` 并写原因）。
- 如果使用生成图/实拍：记录来源、授权/状态、用途。
- 如果是纯程序化：明确“风格化目标”，不要用“电影感/高级感”当验收。

## 5. 首帧质量门槛（still gate）

静帧必须同时满足：

- 主体/焦点一眼可辨；
- 光有方向，暗部不是死黑，受光面有层次；
- 至少两个面能看出材质差异，而不是同一套纯色；
- 文字完整、可读、不压主体；
- 暂停时不像 PPT/信息图；
- 没有“硬边多边形光、半圆杯子、通用暗背景+大字”这类占位符。

不满足就改静帧，不写动画。
