# Film Plan（导演处理）

> 一页导演处理，不是审批表，也不是分镜 schema。
> 多镜头/长片写；单镜头可只写关键画面。
> 它服务于画面，不是让模型填字段。如果写到最后只是在填表，删掉，回到参考和画面。

## 2. 关键画面

写 3–5 个“必须成立”的画面。每个画面回答：

- 画面里有什么（主体/空间/光/材质）？
- 为什么这个画面值得存在？
- 它承担什么叙事/情绪功能？
- 如果删掉它，片子会损失什么？

## 3. 镜头与转场

可以列 shot list，但不要为了字段牺牲画面。

每个镜头只问：

- 观众第一眼看到什么？
- 镜头为什么在这个位置/高度/景别？
- 光从哪来、落在什么材质上？
- 这一镜有什么是只有画面才能说的？
- 为什么从这里切到下一镜（动作/视线/形态/光位/时间/情绪）？
- 下一镜继承什么、重置什么？

不需要固定镜头数、固定转场类型。硬切、长镜头、留白都可以，只要有理由。

## 6. 可选：animatic / 粗剪

多镜头可以先做低成本 animatic 验证节奏和切点，但它是工具，不需要 review JSON 或通过状态。

- 看什么：时间线是否成立、事件是否有因果、切点是否有理由、结尾是否收束；
- 如果 animatic 像幻灯片，先改镜头组织/关键画面，不要急着加材质；
- animatic 通过后再做精细画面，不需要审批门。

## 7. 自检

1. 去掉字幕，视觉弧还成立吗？
2. 关键画面是否真的“关键”，还是只是过场？
3. 有没有一个镜头是只有画面才能表达的？
4. 切点有理由吗，还是每段结束就换图？
5. 结尾是动作完成，还是对象停住？
6. 这份 plan 是在帮助画面，还是已经变成填表？
