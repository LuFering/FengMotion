# Quality Bar / 看片问题

> 这不是 pass/fail 门禁，也不是审美打分器。
> 它是一组看片时用来定位问题的问题：哪里像目标、哪里最 generic、下一轮只改什么。
> 技术底线单独列在最后；技术通过不等于画面成立。

## 1. 第一眼

- 观众第一眼看到什么？这个焦点是主动选择的吗？
- 画面有没有一个视觉命题，而不是只有“氛围”？
- 有没有一帧值得暂停、截图、记住？是哪一帧？
- 核心视觉事件是什么？观众能一眼读出来吗？
- 每个镜头是否改变了“我在看什么”？还是只是换了一个物体？
- 如果把字幕拿掉，第一眼还能看懂在发生什么吗？

## 2. 画面

- 构图：焦点/留白/前后景/视觉动线是否成立？还是所有东西平均用力？
- 光：方向、软硬、衰减、受光面、接触阴影是否清楚？暗部有层次还是死黑？
- 材质：背景/台面/主体/道具是否能区分？有没有“所有东西同一种塑料感”？
- 色版：颜色有角色分工，还是单一棕色/灰色糊成一片？
- 镜头：景别/机位/景深是否服务内容？还是所有镜头同一机位？
- 细节：哪些细节让画面可信？哪些细节只是装饰？

## 3. 运动

- 运动是由事件驱动，还是为了“有动效”而漂移/缩放？
- 关键动作有没有 start → middle → end，还是只出现对象？
- 中间态是否可信？有没有突然跳变？
- 静止是有意停顿，还是动作没做完？
- 动作的路径/速度/停顿有设计吗？还是匀速插值？
- 动作是否有表现力：事件发生 → 清楚可信 → 有重点/节奏，而不只是“完成任务”？
- 关键动作的预备/触发/接触/反应/停顿，哪一拍最值得看？
- 光/阴影/液体/粒子/材质是否对动作作出反应？
- 镜头运动有理由吗？速度/停顿/跟谁？还是在掩盖构图问题？
- 切点是否继承动作/状态，还是跳变？
- 这些问题只能用连续画面判断；如果只看静帧/接触表，要明确记录“未做连续播放审片”。

## 4. 叙事与字幕

- 画面本身能说明事件/因果吗？还是主要靠字幕解释？
- 字幕/旁白是否在复述画面？如果是，删掉或改画面。
- 每个镜头是否有“只有画面才能说”的东西？
- 事件之间是自然衔接，还是每段换一张图？
- 去掉字幕看一遍，事件链还成立吗？
- 原文/用户要求的事件都在吗？哪些被删/背景化？有没有替代呈现？

## 5. 结尾

- 最后一个动作完成了吗？还是对象被“放”到画面上？
- 结尾和开场有呼应吗？是空间/光/构图/声音的呼应，还是只是同一个背景？
- 最后几秒是收束，还是停滞？
- 全片有视觉高潮吗？哪一个瞬间是重点？
- 观众最后带走的是什么画面/情绪？

## 6. 常见失败模式

- 默认暗背景 + 渐变光 + 居中大字；
- 几何占位符冒充材质；
- 每个镜头都同一构图/同一机位；
- 用粒子/发光/抖动掩盖没有事件；
- 字幕解释一切，画面只是插图；
- 动作只有首尾，没有中间态；
- 结尾对象停住，没有完成动作；
- 参考只借了颜色，没有借光/材质/构图/镜头。

## 7. 审片方式

- 能连续播放就连续看；连续看才能判断节奏、接触反应、切点和高潮。
- 不能连续播放时，用密集抽帧/时间序列（例如 4–6 fps 接触表 + 关键动作帧）替代，并明确写“未做连续播放审片”。
- 不要把抽帧结论冒充完整看片；不要只检查首帧和尾帧。
- 具体 finding 带时间点/帧号/观察/下一步；没有证据的判断标为“推断”。

## 8. 一轮只改一个最大问题

看完一遍，按“如果只改一个，哪个提升最大”排序：

1. 视觉方向/媒介不对；
2. 构图/焦点不对；
3. 光/材质不对；
4. 镜头/运动不对；
5. 字幕/节奏不对；
6. 结尾不对。

只改第一个；改完再拍一次，不要同时改五件事。

## 9. 技术底线（这些必须过）

- 可播放、规格正确、无损坏；
- ffprobe 检查分辨率/fps/帧数/音轨/pix_fmt/color_range/color_space；
- 资源路径真实存在；
- 原文要求逐字保留的内容没有遗漏/改写；
- 没有伪造参考/素材/渲染/批准；
- `sketch`/`prototype` 明确标记非交付。
