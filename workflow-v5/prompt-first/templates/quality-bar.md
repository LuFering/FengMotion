# Quality Bar（首帧/首版质量门槛）

> 这不是审美打分器，是防止“能渲染但像占位符”的最低线。
> 每条填 `pass / fail / n/a`，fail 必须写证据和下一步；静帧 fail 不允许进入完整动画。

## A. 静帧检查

| 项 | 标准 | 结果 | 证据/问题 |
|---|---|---|---|
| 焦点 | 第一眼知道看什么 |  |  |
| 构图 | 主体/留白/层次成立，不像幻灯片 |  |  |
| 光 | 有方向、有衰减、暗部有层次 |  |  |
| 材质 | 至少两个面能区分材质 |  |  |
| 色彩 | 不是单一棕色/灰色糊成一片 |  |  |
| 文字 | 完整、可读、层级清楚 |  |  |
| 媒介诚实 | 没有假装程序化=摄影 |  |  |
| 暂停测试 | 暂停像设计画面，不像 PPT |  |  |

## B. 首版动画检查

- 运动有因果，不是装饰性漂移/缩放；
- 关键变化有中间态，不是瞬间跳变；
- 文字出现时间与画面事件不互相抢；
- 没有为了“有动效”加粒子/发光/抖动；
- 镜头运动（推/移）有理由，且不掩盖构图问题。

## C. 迭代纪律（省 token）

1. 静帧不过，不写完整动画。
2. 首版只做 1 个关键镜头/3–5 秒 proof，不直接全片。
3. 每轮只修 1 个主要问题；用静帧/短片段验证，不重渲全片。
4. 问题按层归属：媒介/构图/光/材质/运动/文字；不要用“加特效”跨层掩盖。
5. 如果连续两轮仍在修同一层，停下来换媒介或换视觉目标，而不是继续微调。
6. 每次迭代记录：问题、证据帧、改动、结果、是否解决。

## D. 失败时的优先顺序

1. 媒介不对 → 换实拍/生成/混合，或明确接受风格化上限；
2. 构图不对 → 改主体/留白/层次；
3. 光不对 → 改方向/软硬/受光面；
4. 材质不对 → 加真实素材/纹理/生成图，不堆 CSS 渐变；
5. 运动不对 → 改状态变化/时间，不加速度线/粒子；
6. 文字不对 → 改层级/位置/对比，不靠阴影硬撑。
