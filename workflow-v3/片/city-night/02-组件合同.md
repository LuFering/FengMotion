# 《当城市进入夜晚》· 02 组件合同

> 自研举证：看过 `brand-frame-snap`（画框先于内容出现，框内套景）与 `skeleton-reveal`（草稿→骨架→内容的逐级显影）。
> 两者都是产品 UI 包装语法，不能直接套到城市叙事上；本片只借“框内套景”和“逐级显影”的时序。
> 光枝生长另参考 `workflow-v3/examples/seed-growth` 的 `pathLength` 写法（示例，不作为库组件）。

| 组件 | props（可序列化） | 机制 | 来源 | 事件 | 验收帧 |
|---|---|---|---|---|---|
| `SkylineTitle` | horizon / seed / title | 程序化楼群 + 窗光波前 + clip 标题 + 镜头压向地铁口 | self（借 brand-frame-snap 的框内景） | 窗光亮、标题写出、镜头下压 | 12 / 60 / 150 / 300 / 370 |
| `MetroCrossSection` | stageHeight / ground / trainStartX | 2500px 竖向剖面 + 相机 Y 位移 + 列车位移 | self（参考实拍剖面构图） | 列车掠过、镜头从隧道升到街面 | 377 / 437 / 557 / 647 / 663 |
| `Triptych` | windowWidth / windowHeight / focus | 三个 clipPath 窗内景 + 镜头焦点位移 | self（借 skeleton-reveal 的逐级显影） | 屏幕熄灭、画框上墙、代码跑通炸光 | 684 / 754 / 834 / 914 / 979 |
| `GrandOrb` | orbX / orbYStart / orbYEnd / orbR | 径向渐变球 + 射线 + 相机推进 + 白场 | self | 光球升起、推进、白场 | 1000 / 1040 / 1100 / 1150 |
| `DeskLight` | lamp / seed / branches | 台灯特写拉回 + 多组 pathLength 光枝 + 穿窗光路 | self（pathLength 参考 seed-growth） | 光枝分三批生长、汇成一条 | 1165 / 1220 / 1300 / 1400 / 1450 |
| `PossibilityWave` | figureStartX / walkStart / speed / footprintEvery | 窗光波前 + 步态摆腿 + 逐帧脚印 | self | 城市亮起、人物走、脚印留痕 | 1500 / 1560 / 1600 / 1660 |
| `Dawn` | horizon / seed / sun / sunR | 颜色插值天空 + 反向窗光 + 太阳 + 鸟 | self | 天亮、窗灭、日出 | 1700 / 1760 / 1830 / 1900 / 1920 |
| `Ending` | window / figureX / stepPx | 窗内景 + 人物位移 + 黑场片名 | self | 迈一步、收片名 | 1970 / 2040 / 2110 / 2125 |

## 硬约束

- 所有组件只吃 `props + useCurrentFrame()`，无 `Math.random`（统一 `mulberry32` 固定种子）。
- 画面资源只有 `public/city-night/grain.png`、`mix.m4a`；没有照片、没有外部视频。
- `eventFrames` 与 `durationInFrames` 分开：光球 985–1157 内完成，白场留到 1157；台灯从 1157 一直留到 1464。
- 每个组件可单独渲染：`npx remotion still remotion/index.ts CityNightFilm out/f.png --frame=N` 即可验证。
