# 《当城市进入夜晚》· 01 创意意图

## 1. 一句话

城市从入夜到天亮，八场戏讲的不是城市，是那些在夜里悄悄做出一个小决定的人。

## 2. 叙事

| 场 | 文案 | 画面事件（不是运镜） |
|---|---|---|
| 1 | 当城市进入夜晚 / 你有没有想过… | 城市窗光由左至右逐栋亮起，标题被遮罩写出，镜头向地铁口压下 |
| 2 | 地铁…写字楼…咖啡店… | 地下剖面：列车进站掠过，镜头沿楼梯井垂直升到街面，写字楼仍亮、咖啡店将打烊 |
| 3 | 有人结束工作 / 有人开启新生活 / 有人凌晨三点… | 三联窗：显示器熄灭、画框挂上墙、屏幕代码跑通并炸出一点光 |
| 4 | 我们总以为，改变世界需要一个宏大的开始 | 一颗过大的光球从楼后升起，镜头一路推进光里（刻意过度宏大） |
| 5 | 但其实，一次新的尝试… | 光球切成台灯灯泡；桌面上一个光点长出三组光枝，最后汇成一条穿窗而出 |
| 6 | 世界从不缺少可能性…那一步 | 城市窗光成波前亮起；屋顶上一个人往前走，每一步留下发光脚印 |
| 7 | 当第一缕晨光… | 与开场同一座城市：窗光反向熄灭，太阳从近排楼后升起，鸟群过场 |
| 8 | 而你，只需要继续向前 | 清晨窗前，一个人背对镜头向前迈出一步；黑场，片名卡 |

## 3. 视觉系统

- 底色：`#04060B` / `#05070E`；城市远层 `#0C1B30`，中层 `#0A1728`，近层 `#050C16`，最近层 `#02050A`
- 暖光：窗光 `#FFC578`，钨丝 `#FFD9A0`，强调 `#FFB25E`
- 冷光：屏幕 `#A9D4FF`，街灯反射 `#8FB8E0`
- 纸/字：`#F3E7D3` / `#F7EDDB`；辅助字 `#BDAF94`
- 字体：标题 Noto Serif CJK SC 500；正文/字幕 Noto Sans CJK SC 300
- 构图：单帧一个焦点；标题在左三分之一，城市在右；字幕在下安全区（距底 64px）
- 层级：天空 / 远中近四层楼 / 街道或室内 / 前景框（窗框、屋顶、字幕）
- 材质：统一 35% 软光颗粒 + 暗角；不用照片，不追写实，走“印刷感城市插画”
- 运动：窗光是波前不是齐亮；镜头位移只做包装，每场必须有一个主体事件（亮/灭、开/合、生长、迈步）

## 4. 声音

- 旁白：Edge TTS `zh-CN-YunxiNeural`，rate -8%，pitch -2Hz，逐句合成后按词边界对齐字幕
- 音乐：程序化环境铺底（A 小调 → C 大调，55.8s 处日出渐强），侧链让位于人声
- 混音：人声 -16 LUFS，音乐在旁白下自动下压

## 5. 记忆点（必须能在成片里指出来）

1. 第 12.6s：镜头从地铁剖面沿楼梯井升到街面（一镜跨两层）
2. 第 22–32s：三联窗三种夜生活同时发生
3. 第 38.5s：巨大光球硬切成一只台灯灯泡
4. 第 48.8s 起：屋顶上的脚印一条线亮过去
5. 第 55.8s 起：同一座城市天亮，窗光反向熄灭

## 6. 反面清单

- 不用“照片 + 推拉 + 光效”冒充事件
- 不让光效单独承担叙事（光变必须伴随主体变化）
- 不用全片统一的缓推代替剪辑节奏
- 不把“高级感”当风格说明；色值、字号、层级都写死
