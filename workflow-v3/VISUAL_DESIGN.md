# 视觉设计 · v3

> 视觉规范不是“选一张好看的静帧”，是**在运动里仍然成立的系统**。
> 每一条规范都要能回答：它在 t0、tmid、t1 分别是什么样。

---

## 0. 视觉身份门（写代码之前）

没有参考、没有 `DESIGN.md` 时，**先问 3 个问题**，写进 `visual-identity.md`：

1. **情绪**：explosive / cinematic / fluid / technical / chaotic / warm / 其他
2. **画布明暗**：暗底还是亮底；底色偏暖还是偏冷
3. **品牌色 / 字体 / 参考**：具体 hex、字体、参考片名；没有就写“无”

> 默认“暗底 + 暖强调 + 居中 + 霓虹”是模型的懒惰答案。
> 不问清楚就开写，成片会和上一部长得一样。

## 1. 风格系统

| 项 | 要写什么 | 不合格 |
|---|---|---|
| 色板 | 底 / 主 / 次 / 强调 / 光；给具体值 | “高级灰”“科技蓝” |
| 字体 | 字体族、字重、字号、行高、字距 | 只写“宋体” |
| 构图 | 安全区、焦点数上限、地平线/视觉中心 | 只给参考图 |
| 层级 | 背景 / 中景 / 主体 / 前景 / 叠加 | 不分层，所有元素同一平面 |
| 材质 | 允许的质感（纸、金属、玻璃、颗粒） | “有质感” |
| 运动 | 入场/退场/停顿/转场的规则 | 只写“流畅” |

---

## 2. 设计不是静帧

每个视觉决定都要写**它在运动中如何保持**：

- 字：是逐字出现、整体位移，还是被遮罩揭示？字号在运动中有没有变？
- 主体：是形状在变，还是只有位置在变？变形时描边/填充怎么处理？
- 光：是照亮主体，还是替代主体？光效有没有叙事作用？
- 构图：镜头不动时，画面靠什么维持注意力？

> 只写“最终画面长什么样”，AI 会做一张图，然后给它加位移。

---

## 3. Token 作为输入，不写死

- 色板、字号、间距、圆角、缓动曲线，统一放在 `theme.ts` 或 props；
- 组件不许内部硬编码品牌色/字体；
- 换片只换 theme，不改组件结构；
- 主题值必须能序列化，进 scene spec 的 `props` 或全局 `theme`。

---

## 4. 与场景规格的关系

- `VISUAL_DESIGN.md` 定“系统”：色、字、层级、材质、运动原则；
- `scene.spec.json` 定“这一场”：组件、props、帧区间、验收帧；
- `COMPONENT_CONTRACT.md` 定“这个组件怎么实现”；
- 三者冲突时：**契约 > 场景规格 > 视觉设计**（工程可行性优先）。

---

## 5. 检查

- [ ] 色板/字体/层级都有具体值，不是形容词；
- [ ] 每条规范都写了“运动中如何保持”；
- [ ] 没有把最终画面写死成一张静帧；
- [ ] 组件不硬编码主题值；
- [ ] 遮住字幕，画面仍能传达层级和焦点。
