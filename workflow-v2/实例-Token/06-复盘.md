# 06 · 复盘

> 每次返工都要落一条，否则下一期还会踩同一个坑。
> 分类只有两种：**规则没写** / **写了没执行**。

## 模板

```markdown
## <日期> · <段号 / 镜号>

**用户原话**（照抄，不改写）：

**发生了什么**：
<具体到帧/参数/位置，不写"效果不好">

**分类**：规则没写 / 写了没执行

**根因**：
<为什么规则没写，或为什么没执行>

**新规则**（只写一条，能判定的）：
- [ ] <规则>

**规则落在哪**：DESIGN.md / 05-QA.md / 01-大段表.md / 02-镜头剧本.md

**是否已验证**：是 / 否
```

---

## 示例

## 2026-10-17 · D02 句 9

**用户原话**：「这一段看着像 PPT，字在动但底下什么都没发生。」

**发生了什么**：句 9 的 20.8s 长镜只做了"字逐字出现"，底部空槽没有出现，扫描光只扫了一遍就停。

**分类**：规则没写

**根因**：段剧本只写了"字在蹦"，没写"底下空着"这个对照关系；关键状态里也没有"空槽可见"这一条。

**新规则**：
- [ ] 长镜（>10s）必须在段剧本里写出至少 2 个状态变化，并在关键状态里各有一条证据

**规则落在哪**：02-镜头剧本.md（模板第 ③ 项）、03-关键状态.md

**是否已验证**：否
