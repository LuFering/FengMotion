## 4. 能跑通吗（结论）

**能跑。** 三点依据：

1. `timeline.ts` 是唯一时间来源，`SHOT_COMPONENTS` 缺失的镜自动落 `Placeholder`，**不会报错**，所以加段、加文档、加剧本都不会打断渲染；
2. 段只是文档层 + 目录层，不动 `timeline.ts` / `script-v4.json` / `shots/` 路径；
3. `tsc --noEmit` 当前 0 error，新增文档不参与编译。

**但有一个"看起来能跑"的坑**：37 镜是 `Placeholder`，成片能渲染、能导出，**内容是占位图**。所以流程里"段验收"必须包含一条：**该段所有镜不再是 Placeholder**，否则验收通过是假的。
