# 03 · 关键状态（段级证据）

> 每段 3–5 条，覆盖**起 / 止 / 转换**三类。不是每镜一张，也不是按秒数凑图。
> 每条都要能在最终工程里复现，不能只存在于草稿。

## 模板

```markdown

| 1 | | 起 | | | `段/D0x/状态/01.png` |
| 2 | | 转换 | | | |
| 3 | | 止 | | | |
```

## 实例：D02 · 看不见

| # | 状态 | 类型 | 对应 | 判据 | 证据 |
|---|---|---|---|---|---|
| 1 | 价格标签空着 | 起 | 句 7 | 标签可见、无数字；观众能看出"该有价格但没有" | 待截 |
| 2 | 扫描光穿过界面 | 转换 | 句 9 前段 | 光带边缘清晰，不糊成一片；扫过时界面元素不变形 | 待截 |
| 3 | 0.4s 黑场 | 转换 | 句 9「没有」 | 时长 0.4s±1 帧；黑场前后主体位置连续 | 待截 |
| 4 | 字排满 + 底部空槽 | 止 | 句 9 后段 | 字在动、底部空槽可见；空槽不被字遮住 | 待截 |
| 5 | 纸盖住账单 | 止 | 句 10 | 纸落下后账单仍隐约可见；不出现"完全消失" | 待截 |

## 高风险段的过程预演

满足任一条就要做：

- 这一段用了**没做过的类型**（新材质/新运动/新镜头语言）；
- 关键状态里有 1 条以上**说不出判据**；
- 上一版这段被否过 2 次以上。

预演做法：用简化画面（色块/文字即可）+ **真实配音**，把整段按最终时长跑一遍，只看"过程成不成立"，不看材质。
预演不过 → 改剧本，不进入制作。
