## 1. 静态外观

### 色板
| 用途 | 值 |
|---|---|
| 底 | `#000000` |
| 主文字 | `#EDEDED` |
| 次文字 | `#9A9A9A` |
| 强调 | `#3B8CF8` |
| 分隔线 | `#2A2A2E` |
| 警示/数字高亮 | `#E0A64B` |

### 字体
| 层级 | 字体 | 字号（1920×1080） |
|---|---|---|
| 标题 | Noto Serif CJK SC / 思源宋体 | 96–120 |
| 副标 | 同上 | 40–48 |
| 正文 | Noto Sans CJK SC | 24–28 |
| 注释 / 时间码 | Noto Sans Mono CJK SC | 14–16 |

### 构图
- 安全区：左右各留 120px，上下各留 80px；
- 标题默认左对齐，起始 x = 160px；
- 一屏最多 2 个视觉焦点，超过就拆镜；
- 数字类信息居中或右对齐，不跟标题抢左边界。

### 图形语言
- 圆角 2–4px，描边 1px；
- 不用渐变底、不用彩色外发光；
- 卡片/标签用「细线 + 深底」，不用实心色块；
- 图标与文字同色系，不做双色。

## 2. 动态

| 项 | 规则 |
|---|---|
| 入场 | 400–600ms，`easeOutCubic` |
| 退场 | 300–400ms，`easeInCubic` |
| 位移 | 单次不超过画面宽度的 1/3 |
| 停顿 | 关键信息落地后 ≥ 0.4s |
| 转场 | 只用：硬切 / 黑场 / 同形状过渡；**禁止**旋转翻页、缩放穿越 |
| 跟随 | 镜头只跟主对象，不跟背景 |

## 3. 禁止项

- 弹跳（spring 过冲）；
- 彩色发光 / 霓虹外溢；
- 同一屏 3 个以上元素同时启动；
- 文字逐字随机延迟（除打字机段落）；
- 用 CSS 画一个"像素材"的东西凑数。

## 4. 例外

打字机段落（句 9）、0.4s 黑场（句 9 的"没有"）是**有意为之**，不算违反"停顿/转场"规则。
