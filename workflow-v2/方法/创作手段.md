# 创作手段（让 AI 从"执行"变成"创作"）

> 检查只能防低，不能拔高。拔高靠这些手段。
> 不是每条都用；按片型、时长、风险挑 3–5 个。

---

## 1. 情绪板（look dev）

**是什么**：3–5 张真实画面（参考片抽帧、自己的候选、摄影/电影截图），定色温、质感、对比、留白。
**什么时候**：DESIGN 之前。
**产出**：一张拼图 + 一句话"这条片子看起来像什么"。
**为什么有效**：文字描述"高级/电影感"没有约束力；一张图能同时定十个参数。

## 2. Beat 拆解（借结构）

**是什么**：把对标片的一段拆成 4–6 个 beat（起、承、转、合、停顿），标出每个 beat 的时长与动作。
**什么时候**：划段之后、写剧本之前。
**产出**：一张 beat 表 + "借哪几个 beat、不借什么"。
**为什么有效**：借结构不借皮，才不会做成"像但不对"。

## 3. 一段三概念（讲法，不是画法）

**是什么**：同一段写三种讲法——比喻 / 对比 / 数据 / 拟人 / 反问——各一句话，选一个。
**什么时候**：段剧本之前。
**产出**：三行字 + 选定理由。
**为什么有效**：大多数"PPT 感"不是画得不好，是讲法本身是"陈述句配图"。

## 4. Animatic 草稿（先看节奏）

**是什么**：用色块/剪影/大字做 10–15fps 的粗剪，带真实音乐或配音，先看镜头长度与节奏。
**什么时候**：正式制作前，尤其长片或转场多的片。
**产出**：一条 30–60s 的粗剪视频。
**为什么有效**：节奏问题在粗剪阶段最便宜；等精做再改，成本十倍。

## 5. 限制驱动

**是什么**：每段给自己一条限制——只用一个镜头运动 / 只用一个颜色 / 只有一个主体 / 只用一个转场。
**什么时候**：卡住、或者画面太"平均"时。
**产出**：一条写在剧本第 ⑦ 项的约束。
**为什么有效**：限制逼出选择；没有限制时，AI 会平均地放一点动效，结果什么都不突出。

## 6. 声音先行

**是什么**：先做 15–30s 音乐/氛围，按节拍排镜头，而不是做完画面再配乐。
**什么时候**：音乐驱动型片子。
**产出**：一条音轨 + 一张节拍点表。
**为什么有效**：节拍是最便宜的运动来源；画面跟着节拍走，天然不"平"。

## 7. 镜头语言变化表

**是什么**：景别 / 机位 / 运动 / 焦点，四列，每段至少变一项。
**什么时候**：划段时。
**产出**：一张表；连续两段四项都一样就标红。
**为什么有效**：构图重复是"像 PPT"的第二大原因（第一是没运动）。

## 8. A/B 双版本

**是什么**：高风险段做两个版本，运动语法不同（例：一个推镜、一个硬切蒙太奇），让用户选。
**什么时候**：只有高风险段，不要全片。
**产出**：两条 5–10s 片段。
**为什么有效**：比"三个方案"聚焦；用户能直接说"要 A 的节奏、B 的收尾"。

## 9. Art Director 子智能体

**是什么**：让子智能体只看画面（不看代码、不看解释），给"最狠的一句批评"，不给改法。
**什么时候**：每段第一版之后。
**产出**：一句批评 + 一个"如果是我会怎么改"的方向（不给实现）。
**为什么有效**：主智能体容易自我合理化；换一双没参与制作的眼睛，能看见"像什么"。

## 10. 失败博物馆

**是什么**：复盘里记录被否的方案 + 原因 + 用户原话，按题材归档。
**什么时候**：每次复盘。
**产出**：`案例/失败博物馆.md`。
**为什么有效**：下次开片先看，避免重复；也能反向提供灵感（"上次这个思路不行，换个方向"）。

---

## 怎么选（推荐组合）

| 片型 | 至少用 |
|---|---|
| 短片（<60s）、单一情绪 | 情绪板 + 一段三概念 + Animatic |
| 中片（1–3min）、多段 | 以上 + Beat 拆解 + 镜头语言变化表 |
| 长片 / 多段并行 | 以上 + A/B 双版本 + Art Director |
| 卡住 / 画面平均 | 限制驱动 + 失败博物馆 |

> 手段是给你"往上加"的，不是评分表。用了几条不重要，重要的是**有一条真的改变了片子**。
