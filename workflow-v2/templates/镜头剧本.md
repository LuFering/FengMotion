# 镜头剧本 · <片名>

> 门 2 的后半。一段一份，**写完审一次，审过才允许出图**。

## 模板

```markdown
## <段号> · <段名>（句 a–b / 镜 x–y / 时长）

### ① 声音给了什么
<逐句列信息点，不写画面>

### ② 画面要新增什么
<这段结束时观众多知道了什么；不能是"把配音换成大字">

### ③ 主对象怎么变
<起 → 中 → 止；同一对象的状态变化，不是换对象>

### ④ 镜头怎么带人看
<固定/推/拉/焦点交接；什么时候动，动多少>

### ⑤ 高潮与停顿
<高潮在第几句；停多久；为什么停这里>

### ⑥ 取材
<从哪张卡/组件/参考段来；抄哪些参数；参考段的时间码与抽帧图>

### ⑦ 边界
<不许出现的元素；与上一段/下一段的接点>

### ⑧ 运动设计（三问，答不出就不许写代码）
1. 观众的眼睛从哪移到哪？
2. 什么东西在动：主体 / 镜头 / 光 / 环境？（至少一类）
3. 幅度多大：位移 __% 画宽/秒，或缩放 __%/秒，或亮度变化 __%
   （对照本片运动合同；合同没写就回去补，不许拍脑袋）

### ⑨ 记忆点
<这一段观众会记住的那一下；没有就删段，不要凑>
```

## 硬规则

- **长镜（>10s）必须写出至少 2 个状态变化**，否则拆镜；
- **每一段都要有 ⑥ 取材**：写不出 = 卡点没过，不许进制作；
- **⑧ 运动设计三问答不出，或幅度低于下限**：不许进制作；
- **⑨ 记忆点写不出**：这一段先别做，回去改段表；
- ⑥ 里的 demo 路径 / 时间码必须真实存在，`check-shot.py --provenance` 会验；
- ⑦ 的接点必须写具体（上一段末帧是什么、本段首帧是什么）。
