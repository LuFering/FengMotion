# 镜头剧本 · <片名>

> 门 2 的后半。一段一份，**写完审一次，审过才允许出图**。

## 模板

```markdown
## <段号> · <段名>（句 a–b / 镜 x–y / 时长）

### ① 声音给了什么
<逐句列信息点，不写画面>

### ② 画面要新增什么
<这段结束时观众多知道了什么；不能是"把配音换成大字">

### ③ 主对象怎么变
<起 → 中 → 止；同一对象的状态变化，不是换对象>

### ④ 镜头怎么带人看
<固定/推/拉/焦点交接；什么时候动，动多少>

### ⑤ 高潮与停顿
<高潮在第几句；停多久；为什么停这里>

### ⑥ 取材
<从哪张卡/组件/参考段来；抄哪些参数；参考段的时间码与抽帧图>

### ⑦ 边界
<不许出现的元素；与上一段/下一段的接点>

### ⑧ 事件合同（答不出不许写代码）

- **起态**：画面开始时，主体在哪、是什么状态
- **事件**：这一镜里发生了什么（主体动作 / 状态转变 / 信息揭示 / 空间关系变化）
  —— "推近 / 光扫 / 亮度变化"不算事件，只能写进"镜头语言"
- **止态**：事件结束后，主体变成什么状态
- **时间**：事件从第几秒到第几秒
- **证据**：成片里看哪一帧 / 哪一秒能证明它发生了
- **素材类型与来源**：视频 / 照片 / 图形 / 3D + 具体文件或库
- **镜头语言**：服务于事件，不是替代事件

### ⑨ 记忆点
<这一段观众会记住的那一下；没有就删段，不要凑>
```

## 硬规则

- **长镜（>10s）必须写出至少 2 个状态变化**，否则拆镜；
- **每一段都要有 ⑥ 取材**：写不出 = 卡点没过，不许进制作；
- **⑧ 事件合同答不出（起态/事件/止态/证据）**：不许进制作；
- **⑨ 记忆点写不出**：这一段先别做，回去改段表；
- ⑥ 里的 demo 路径 / 时间码必须真实存在，`check-shot.py --provenance` 会验；
- ⑦ 的接点必须写具体（上一段末帧是什么、本段首帧是什么）。
