## 1. 逐镜表

| 镜 | 起态 | 事件（可观察、可验证） | 止态 | 镜头语言 | 时长 | 素材类型 | 素材来源（具体） | 可得性 | 验收证据 |
|---|---|---|---|---|---|---|---|---|---|
| S01 | | | | | | 视频/照片/图形/3D | | 已有/可生成/需拍/没有 | |
| S02 | | | | | | | | | |
| S03 | | | | | | | | | |

**每一镜必须能回答：**

- **起态**：画面开始时，主体在哪、是什么状态；
- **事件**：这一镜里**发生了什么**（主体动作 / 状态转变 / 信息揭示 / 空间关系变化）；
- **止态**：事件结束后，主体变成什么状态；
- **证据**：成片里看哪一帧、哪一秒能证明这件事发生了。

> "镜头慢慢推近""光扫过""亮度变化"是**镜头语言/光效**，不是事件。
> 它们可以写在"镜头语言"列，但不能填进"事件"列。
