# 段级流程 v2 · 使用说明（给 AI 看的）

> 这是**第二套工作流**，与 `AIremotion-skill/01-流程与检查/02-流程/工作流-四段式.md` 并存。
> 四段式管**一镜之内**怎么做；这一套管**一段之内、镜与镜之间**怎么排、怎么验、怎么交。
> 顺序：**路线 → 概念 → 段 → 镜 → 粗剪 → 段验收 → 整片锁画**。

---

## 0. 门 0：开工检查（硬规则）

**没填完 `00-开工检查.md` 并贴出来，不许写代码、不许采集素材、不许出图。**

四项缺一不可：

1. **稿本 + 时长**：哪份稿、共几句、总时长、帧率（写文件路径）；
2. **DESIGN 候选**：2–3 张真实外观候选；**新片必须新建，不许沿用别的片**；
3. **大段表**：每段任务句 + 节奏三点 + 句/镜范围（覆盖校验必须通过）；
4. **素材需求清单**：每段要什么、类型、有没有；**只列需求，不许先抓**。

> 为什么是"门"：没有门时，AI 会先攒素材、再反推画面。
> 案例：`案例/2026-10-城市之夜.md`（只作参照，不是规则）。

---

## 0.5 门 0.5：创意定标（比 DESIGN 更早）

填 `00-创意定标.md`，七件事：

1. **创作路线 `creative_route`**：实拍蒙太奇 / 动态图形 / 解释型动画 / 混合叙事 / 幻灯片。
   **幻灯片必须由用户显式选择，不能是默认。** 路线要核素材前提（选实拍但没视频 = 不成立）。
2. **五个概念 Pitch**：5 种讲法，至少 2 种"非常规"；不许 5 条都是"照片+推拉+字幕"的变体；用户选一个。
3. **资源路线 `resource_route`**：卡库 / 组件库 / 参考实拍 / 自研；选自研要举证 2 张看过的卡。
4. **先看再想**：打开 8–12 个 demo 源码，写"偷什么"，具体到数字。
5. **反面清单**：这条片子绝不能像什么（PPT / 贴纸 / 海报），写 3 条。
6. **记忆点**：每段至少一个"观众会记住的那一下"。
7. **运动参数**：位移/缩放/静止上限——**参数是约束，不是目标**；推拉 3% 不等于一个事件。

> **工作流是地板，不是天花板。** 检查只在最后兜底；创意必须在这里先立起来。

怎么找卡、怎么读 demo：`方法/用卡库.md`。
怎么把片子拔高：`方法/创作手段.md`（情绪板 / Beat 拆解 / 一段三概念 / Animatic / 限制驱动 / 声音先行 / A/B / Art Director / 失败博物馆）——每片挑 3–5 个用。

## 1. 顺序禁令（违反即停）

| 禁止 | 为什么 |
|---|---|
| 没选 `creative_route` 就做设计 | 会默认滑向幻灯片 |
| 五个概念没出、没选就进制作 | 第一个想到的往往是最省力的 |
| DESIGN 未确认就出图 | 风格会变成每镜各凭手感 |
| 段表未完成就写剧本 | 剧本会按句写，不是按段写 |
| **Storyboard 未完成就写代码** | 事件和素材没定，只能做推拉 |
| **Animatic 未过就正式制作** | 节奏和成立性要到最贵的时候才发现 |
| 素材需求清单未完成就批量采集 | 会变成"素材先行"，拿画面凑文案 |
| 素材静默降级（视频→照片） | 路线会悄悄失效，成片退回 PPT |
| 测试期间修改本流程 | 改前/改后混在一起，结果无法归因 |
| 证据放 `/tmp` | 会被清掉，复盘时无法回看 |

## 2. 流程（门 0 + 12 步 + 4 个门）

```
门 0   开工检查（稿本 / DESIGN 候选 / 段表 / 素材需求）
        ↓
门 0.5 创意定标（creative_route / 5 概念 Pitch / resource_route / 记忆点）
        ↓
① 定稿 + 配音          时基唯一
        ↓
② DESIGN.md            静态候选 → 动态测试 → 落参数        【门 1：风格定稿】
        ↓
③ 划段                 任务句 + 节奏三点 + 风险 + 句/镜范围
        ↓
④ 段剧本               事件合同（起态/事件/止态/证据）      【门 2：剧本确认】
        ↓
⑤ Storyboard           逐镜：起态/事件/止态/镜头/素材/可得性/证据
        ↓
⑥ Animatic             粗剪（10–15fps + 真音乐）            【门 2.5：成立性】
        ↓
⑦ 关键状态             每段 3–5 条，存 shots/S<N>-证据/
        ↓
⑧ 制作                 段内逐镜走四段式；先完整预览再精修
        ↓
⑨ 段内验收             1× 看完 + 确定性 5 条 + 三测 + 技术自检
        ↓
⑩ 接入                 首尾接点 / 时基 / 素材版本
        ↓
⑪ 锁画                 全片 1× 审片 + 创意对账              【门 3：锁画】
        ↓
⑫ 交付 + 复盘          实际文件 1× 审看审听；返工原话 → 规则
```

**四个门**：风格定稿、剧本确认、Animatic 成立、锁画。

### 3.1 新片的工程怎么放（必须二选一，写在门 0 里）

| 模式 | 做法 | 适用 |
|---|---|---|
| **A 新工程**（推荐） | 新建独立 Remotion 工程目录，composition id 另起（如 `<片名>Film`） | 与已有片无关的新片 |
| **B 同工程新合成** | 新建 `timeline-<片名>.ts` + `<片名>Film.tsx`，注册新 composition | 复用素材/组件，但**不许改**既有片的 timeline / 稿本 / 总合成 |

无论哪种，**`--map` 都要为新片重做一份**（镜号→稿号），不许沿用别人的。

## 7. 判定规则

- 路线没选、或选了实拍但没视频素材 → 不许进 DESIGN；
- 五个概念没出、没选 → 不许写剧本；
- 事件合同答不出（起态/事件/止态/证据）→ 不许进 Storyboard；
- Storyboard 里素材可得性写"没有"→ 不许进制作；
- **关键镜素材没"已取得"（只是"可生成/需拍"）→ 不许进正式制作**，只能留在 Animatic；
- Animatic 三个问题任一"否"→ 回 Storyboard 或概念，不许进制作；
- 素材静默降级（视频→照片）→ 锁画判失败；
- 没 1× 看完 → 只能写"未验证"；
- 预览与最终工程两套代码 → 判失败。

## 8. 测试记录

每轮从 0 测试，新建 `RUN-<日期>.md`，只记四件事：

1. 这轮改了什么（版本/提交号）；
2. 卡在哪一步（第几步、哪条门）；
3. 暴露了什么问题（一句话，可判定）；
4. 下轮改什么。

> **测试期间冻结流程**：开跑后不再改 `workflow-v2/`、kit、工具。要改，先停跑、记版本、改完重跑。
