# 图片提取

> 图片能提供“长什么样”，不能提供“怎么动”。

| 维度 | 提取什么 |
|---|---|
| 色板 | 底/前景/强调的 hex；冷暖；对比度 |
| 构图 | 主体位置、留白比例、地平线、焦点数、是否居中 |
| 材质 | 纸/金属/玻璃/颗粒/手绘/实拍 |
| 字体 | 衬线/无衬线、字重、字号层级、字距 |
| 光 | 方向、硬度、色温、轮廓光/体积光 |
| 密度 | 每屏元素数量、信息层级 |

## 做法

1. 用 vision 读整图；
2. 取 3 个主色 hex（不要凭感觉写“暖金”）；
3. 裁一块局部看材质/字体；
4. 写进 `visual.references`，`what` 写“这张图提供什么”；
5. 不把图片内容当成叙事（图里有地铁 ≠ 片子里要出现地铁）。

## 输出

- `visual.references[]`：`{type:"image", path, what}`
- `visual.palette`：可复用则填；只是参考则留给风格帧。
