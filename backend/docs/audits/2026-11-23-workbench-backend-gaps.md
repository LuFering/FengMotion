## 本轮已修复

| 场景 | 原行为 | 修复结果 |
|---|---|---|
| 排队任务取消 | 保持 accepted，占用队列与项目名额，直到轮到它执行 | 持久化 cancelled，立即移出队列，释放项目和队列名额；旧请求重放仍为 cancelled |
| 服务关闭 | shutdownNow 丢弃排队 Runnable，内存 active 仍在，查询可能一直 accepted | 排队任务记录 interrupted；运行任务接收关闭标记及中断，收尾后释放项目锁，最多等待执行器五秒 |
| 渲染器吞掉中断 | 只看线程中断位，取消后仍可能提交新版本 | 独立取消标记参与快照执行、渲染返回与提交前校验，拒绝未提交结果并清理视频和快照 |
| 已完成任务重试 | 先读工作区，源码目录不可用时取不到原结果 | 先验证持久化请求身份并回放结果；新请求仍校验当前项目、版本及源码 |
| 恢复历史与预览写回并发 | 恢复只持 Java 项目锁，Node 手动写回没有互斥 | 共享写入锁覆盖源码恢复、版本提交和失败回滚，占锁时返回 source_busy |
| 普通工作稿 Agent 直接改原文件 | 非精准 draft 直接运行在原项目，模型失败及手动并发修改可能留下半改稿 | 所有显式 draft 先在副本生成；全工程候选在锁下复核原始基线，再应用 src/public/config/package 的多文件变更；普通异常回滚原稿，成功后清理备份 |
| 创作引擎吞掉中断 | 候选写回只检查线程中断位 | 制作作业向精准及全工程候选传递独立取消检查，即使引擎清掉中断位也拒绝尚未应用的候选 |
