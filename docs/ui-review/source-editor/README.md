# 场景编辑器重构验收记录

日期：2026-10-29。状态：实现与开发验证完成，等待用户验收。截图和测试素材不是用户确认，也不是用户视频成片。

## 能力与边界

| 能力 | 已绑定 HTML + GSAP | 原生 Remotion 图层场景 |
| --- | --- | --- |
| 预览 | 运行真实源工程与原 GSAP 动画 | 官方 Player，预览与导出共用合成组件 |
| 编辑对象 | 真实文本、图片、源元素 | 文字、图片、视频、声音、形状 |
| 属性 | 文本、字体、颜色、图片替换、增量位置/缩放/旋转/透明度/可见性 | 布局、颜色、字号、裁切、音量、素材起点、入出点、入退场动画等，按图层类型显示 |
| 画布交互 | 点击选择真实元素 | 点击选择、拖动图层位置 |
| 保存 | 本机覆盖记录，不改原文件 | 本机文档与素材库文件 |
| 工程交换 | JSON/ZIP，源与依赖完整打包 | 应用场景 JSON/ZIP，包含实际素材；不是完整 Studio 源项目 |
| 视频导出 | 尚未接通，界面明确提示 | 实际浏览器 H.264 MP4，保存素材库并进入工作台预览 |
| 帧导出 | 尚未接通 | 实际 PNG |

Remotion 没有统一固定数量的业务参数；可编辑内容取决于组成视频的组件和文档模型。此重构建立了实际图层模型，移除了旧的七项标题覆盖。当前不是完整官方 Studio，不支持任意 TSX 项目或从 MP4 反推图层。暂未提供自由关键帧曲线、整片拼装、HTML 编码器或云端渲染。Token 源清单只覆盖真实存在的 30 个 HTML 源文件，不据演示成片编造内容。

## 操作路径

打开 `http://localhost:4173/?view=production&project=token` → 顶部「场景编辑器」。选择源场景可编辑原元素；「新建 Remotion」创建原生场景，插入图层、绑定真实素材。点击场景设置修改规格，在右下导出工程/当前帧/场景视频。视频编码依赖当前浏览器能力，失败原因会显示；本机数据应通过工程 ZIP 备份。
