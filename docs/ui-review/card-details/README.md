## 播放与真实数据

- 特效库16项中7项有实际MP4，其余9项仍为静态海报。可见动态卡片进入界面即静音循环；不可见或页面隐藏时暂停/卸载视频。
- 素材默认海报，鼠标进入/键盘焦点进入视频卡片时按需从assetService加载真实文件并静音循环；退出后暂停、复位、恢复海报。播放URL复用素材服务缓存，不另建持久媒体存储。
- 参考片原先只展示静帧并通过RAF模拟时间。本轮去掉模拟播放头，将7组参考片关联到同主题、同画面的现有技法动态示例（6×10s、1×3s，ffprobe核对）；标为动态示例，未声明为额外取得的原片。currentTime驱动时间和当前片段。剩余4组无视频源，显示静帧并禁用播放按钮。
- 首页动态示例默认静音循环；打开片库暂停背景，关闭后恢复。片库内21个卡片全部使用静帧。
