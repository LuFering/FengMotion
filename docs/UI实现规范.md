# FengMotion UI 实现规范

> 配套《页面职责合同》。合同解决"页面干什么"，本规范解决"页面长什么样"。
> 视觉方向来自用户提供的五张示范图（素材库 / 项目总览 / 渲染与交付 / 音频与时间 / 脚本与口播）。
> 学的是**信息密度、视觉层级、面板关系、专业工具感**，不是逐像素复制某个产品。

---

## 一、视觉方向

**目标形态**：专业暗色桌面创作软件。不是 AI 聊天应用，也不是企业管理后台。

- 靠**表面色阶**建立层次，不靠描边、阴影、渐变。
- 真实内容优先：缩略帧、波形、时间刻度、预览动效、状态标记、指标数字。
- 桌面软件交互：快捷操作、清晰选中态、可预测的面板展开/收起、悬停反馈、搜索筛选、详情检查、直接进入下一步的入口。

### 表面色阶（沿用项目 token，不新增）

```
--void #0c0c0c  →  --bg #101010  →  --inset #141414
→  --panel #181818  →  --panel-alt #212121  →  --hover #2c2c2c
```

卡片比面板深一档，卡片内嵌的"字段面板"再深一档——这是示范图里最明显的手法：
**层次靠叠加的深色块，不靠边框线。**

### 语义色

| 用途 | 色 | 说明 |
|---|---|---|
| 主操作 / 选中 / 进行中 | 珊瑚橙 `--brand` | |
| 待处理 / 需要用户判断 | 琥珀 `--gold` | 不是失败 |
| 完成 / 已通过 | 绿 `--success` | |
| 真实失败 / 需关注 | 红 `--danger` | |

状态一律**色 + 文字**，不允许只靠颜色。

### 字号（参考约束，允许为可读性微调）

| class | 尺寸 | 用途 |
|---|---|---|
| 页头主标题 | 15–16px / 600 | 视图标题 |
| Hero / 项目名 | 20–24px / 600 | 仅项目上下文区 |
| 区块头 / 分组条 | 12px / 600 | FOLDERS · FOOTAGE 这类 |
| 正文 | 13px | |
| 元信息 | 11px | 时间码、来源、许可 |
| 次要 | 10.5px | 提示、脚注 |

数字 / 时间码 / 文件名用等宽 `.num`。

### 圆角与间距

圆角统一 8–10px（卡片、按钮、胶囊一致）。间距走 4 的倍数：卡片间距 16–24px，分组间距 28px。

## 二、布局按任务选，不套同一个模板

| 页面 | 骨架 | 依据 |
|---|---|---|
| 项目指挥中心 | 项目上下文条 → 阻塞项/下一步 → 产物 → 变更；右侧检查栏 | 示范「项目总览」 |
| 创作资产中心 | 工具栏 → **按状态分组的网格** → 卡片内嵌字段面板 → 底部计数 | 示范「素材库」 |
| 内容编排中心 | 左脚本（带行号段落）→ 右段落/单元表（按场景分组，行尾缩略图） | 示范「脚本口播」 |
| 时序校验中心 | 差异清单（主）+ 双时间轴（导航）+ 波形/段落 | 示范「音频」 |
| 发布与验收中心 | 统计条 → 筛选 → 交付物表（缩略图/大小/进度/验收徽章/状态） | 示范「渲染」 |
| 资源接入与解析中心 | 导入区 → 来源表 → 解析任务 → 产物审核 | 三段式，不同来源不共用解析流程 |
| 创作技法库 | 效果预览（主）→ 适用判断 → 执行信息 → 应用入口 | 技法以"效果"为主角 |
| 参考片库 | 视频/关键帧（主）→ 拆解证据 → 提取出的做法 | 案例研究 |
| 反馈与规则中心 | 反馈原话（证据）| 规则候选（待审）| 生效规则（含适用范围） | 三栏证据链 |
| 流程与质量保障中心 | 阶段 → 门槛（含证据与阻塞原因）→ 当前项目命中情况 | 验收规范，不是说明文档 |

## 三、可复用组件（复用组件 ≠ 复用布局）

1. **页头区**：标题 + 元信息统计 + 右侧主操作；一行说完"这是什么、有多少、能干什么"。
2. **工具栏**：筛选 / 分组 / 排序 / 视图切换，图标+文字，靠左。
3. **分组条**：折叠箭头 + 分组字段 + 彩色值 + 计数。
4. **卡片字段面板**：卡片下半部内嵌更深的块，字段名小字在上、值（胶囊/chip）在下。
5. **状态胶囊**：色点 + 文字，10.5–11px。
6. **详情检查面板**：右侧或底部，展开/收起可预测。
7. **空态**：一句话说明为什么空 + 一个能做的动作。
8. **未接入态**：按目标形态画全，动作置灰，旁边一句"XX 未接入"。
9. **破坏性操作确认**：停用/移除前弹确认，说明连带影响（引用方数量）与是否保存。

## 四、示范图的具体借鉴点

### 素材库示范 → 创作资产中心
- Hero 换成**项目上下文条**（项目名 + 素材总数 + 已用/未用），不做 300px 大图横幅。
- 工具栏：`全部素材 | 外观 | 字段 | 筛选 | 分组 | 排序`。
- **按状态分组**：可直接用 / 需确认授权 / 已停用。
- 卡片：缩略图（角标=类型）→ 文件名 → 来源·许可 → 字段面板（授权状态 / 用在哪些单元）。
- 底部栏：`N 项 · 其中 M 项未使用`。

### 项目总览示范 → 项目指挥中心
- 顶部面包屑 + 右侧成员/状态；主区上=成片播放器，下=产物分组（文件夹/素材），右=检查栏。
- 改造重点：**把"阻塞项与下一步"提到播放器上方**，它是这个页面的主角。

### 渲染示范 → 发布与验收中心
- 统计条：产物数 / 分析中 / 已完成 / 阻塞 / 错误。
- 表格：缩略图 | 名称 | 大小 | 优先级 | 验收徽章 | 进度 | 状态。
- 借鉴：验收结果用**彩色计数徽章**，不通过的列出具体判据。

### 音频示范 → 时序校验中心
- 顶部工具条 + **警告横幅**（问题类型 + 一键处理）+ 段落列表（编号/时间码/文本）+ 波形轨道 + 底部警告计数。
- 借鉴：问题是主角，时间轴是导航；段落块按映射关系着色。

### 脚本口播示范 → 内容编排中心
- 左=脚本源文（带行号段落），右=按场景分组的段落/单元表（状态 | 编号 | 制作日 | 描述 | 类型 | 缩略图）。
- 借鉴：场景分隔头 + 行尾缩略图 + 状态圆点。

## 五、截图验收

每完成一个视图：
1. 起 dev server，真机截图（1512×950）。
2. 至少截：默认态、选中一项、空态（筛选到无结果）、不可用动作置灰态。
3. 核对：状态与真实数据一致、统计随筛选变化、移除/停用后详情与计数同步。
4. 类型检查与构建通过**不算**验收通过。
