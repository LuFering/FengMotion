# 统一设计系统（design-system）

> **本文件是约束，不是建议。** 新页面只允许使用这里定义的 token、字号与组件。
> 底层事实来源：`src/index.css`（引入顺序）→ `styles/paba/app-slim.css`（底座）→
> `styles/brand.css`（品牌覆盖）→ `styles/fm-components.css`（组件）→ `shell/status.ts`（状态）。
> 参考产品（React Flow / Dify / ShotDeck 等）的皮肤**一律不要**，只借结构与交互。

## 一、颜色（唯一 token 清单，禁止新增未定义颜色）

### 表面（中性偏蓝黑，靠明度递进，不靠边线和阴影）

| token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0E1116` | 应用底 |
| `--surf` | `#161A21` | 面板 |
| `--hole` | `#1E222B` | 凹陷槽（进度槽、输入底） |
| `--line` | `#2A2F38` | 分隔线 / 边框 |
| `--soft` | `#17273C` | 选中底 / 浅色衬底 |
| `--grid` | `#1B2029` | 舞台点阵底 |

### 文字

| token | 值 | 用途 |
|---|---|---|
| `--fg` | `#E9ECF1` | 主文字 |
| `--dim` | `#99A2AE` | 次要文字 |
| `--hint` | `#89929E` | 提示 |
| `--ph` | `#6A7380` | 占位符 / 最弱 |

### 强调与语义

| token | 值 | 语义 |
|---|---|---|
| `--acc` | `#3B8CF8` | 品牌蓝：主操作 / 选中 / 进行中 |
| `--acc-d` | `#2E6FD9` | 强调深色（按压） |
| `--on-accent` | `#FFFFFF` | 强调底上的文字 |
| `--ok` | `#3FBF8F` | 完成 |
| `--warn` | `#E0A64B` | 等待用户决定（不是失败） |
| `--bad` | `#F0708C` | 失败 / 需处理 |

### 首页「纸」层（仅首页/工具页）

`--ht-paper #181C24` · `--ht-paper-back #14171E` · `--ht-edge #2C323C` ·
`--ht-ink #3B8CF8` · `--ht-sidebar #111419` 等（见 `brand.css`）。

### 铁律

- **状态色唯一来源是 `src/shell/status.ts`**（`statusOf()` → `{label, s}`，
  颜色由 `.fm-dot[data-s]` / `.fm-tag[data-s]` 决定）。组件里不许自己写状态色。
- 状态**不能只靠颜色表达**：圆点/色块旁必须有文字。
- 深色主题下 `color-scheme: dark` 必须保持（否则系统滚动条变白）。
- 不做渐变、不做大圆角、不做装饰性阴影、不做统计数字大卡。

## 二、字体与字号

字体：Geist Variable（正文）+ 数字/时间码/路径用 `.num`（等宽 11.5px）。

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| 视图主标题 | 15–16px / 600 | 页面/对象主标题 |
| 区块标题 | 12px / 600 | 面板头、区块头 |
| 正文 | 13px / 400 | 内容 |
| 元数据 | 11px / 400 | 时长、来源、时间码 |
| 次要说明 | 10.5px / 400 | 补充说明 |

**三级必须拉开**：标题必须比正文更醒目；正文不用 14px+（失去工具感）。

## 三、间距与圆角

- 面板内边距 12–16px；区块间距 16–24px；页面内容区左右 24px。
- 圆角：小控件 6–8px；卡片 10–12px；胶囊（标签/按钮）999px。
- 桌面优先；窗口宽度下限按现有断点策略（窄窗不硬挤多栏）。

## 四、可复用组件（复用组件 ≠ 复用布局）

来自 `fm-components.css` 与 paba 底座，新页面直接引用：

| 组件 | class | 用途 |
|---|---|---|
| 状态点 | `.fm-dot[data-s]` | 列表项状态 |
| 状态标签 | `.fm-tag[data-s]` | 需要文字的状态 |
| 时间码 | `.fm-tc` | 等宽时间 |
| 进度槽 | `.fm-slot` | 进度条（`--hole` 底 / `--acc` 填充） |
| 空状态 | `.fm-empty` | 无内容态 |
| 单元项 | `.fm-unit` | 列表项范式（hover 边框 `--acc`） |
| 面板头 | `.panel-head` | 34px 高 12px/600 |

新增共用组件（本次改造将建）：**详情抽屉**、**标签组件**、**搜索框**、**筛选条** ——
三库共用样式与交互，但**不共用页面模板与数据模型**（见 `knowledge-library-spec.md`）。

## 五、页面骨架（三种形态，按任务选）

1. **壳层页**（我的创作/工作流/特效库/参考片库/我的素材）：侧栏 68px 图标轨 +
   可选展开 216px；顶栏（app-header）；内容区 `hm-content`（最大宽度按现有约束）。
2. **工作台类**（制作工作台/编辑器）：全幅、多栏、面板化，不套卡片 Dashboard。
3. **复刻页**（已验收的项目指挥中心/时序校验）：iframe 全区装载（`.acr`/`.atr`），
   保持与壳层无缝（满幅、无白边、无内滚）。

## 六、状态与反馈

- 加载 / 成功 / 警告 / 失败 / 禁用：用 `status.ts` 五键 + 文字，不造第六种。
- 后端未实现的能力：**灰显 + 注明原因**（沿用现有「未接入」模式），
  mock 交互必须明确标注，不得伪装成真实执行。
- 异步操作必须有进行中态与失败态（参考现有导入/解析流程）。

## 七、视觉气质

专业创作软件：信息密度适中、操作明确、视觉内容突出、画布空间充足。
**禁止**：所有页面同一种卡片 Dashboard；滥用渐变、发光、大面积装饰。
