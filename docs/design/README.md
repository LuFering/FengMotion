## 一、产品定位（本次改造的出发点）

FengMotion 不是「视频项目管理器」，而是三个核心能力的组合：

| 模块 | 回答的问题 | 性质 |
|---|---|---|
| 工作流 | 怎么做 —— 可编排、可执行、可修改，改工作流就能做不同类型视频 | 核心能力 |
| 参考片库 | 有什么值得借鉴 —— 镜头/运镜/节奏/转场/风格知识 | 核心能力（创作依据） |
| 特效库 | 用什么方法实现 —— 技法、参数、依赖、可执行状态 | 核心能力（制作方法） |
| 我的素材 | 有哪些文件可以用 —— 图片/视频/音频/字体/模板/生成文件 | 基础设施 |

普通素材管理与两类知识资源**分离**：参考片库是「视觉探索型」、特效库是
「技法目录型」、我的素材是「文件管理型」——三套页面结构、三套数据模型。

## 四、可复用能力（改造时保留，不重写）

- **监看器**：Workbench 的 Remotion Player + 真实成片 `/media/token-full-legacy.mp4`
- **数据层**：`src/data/{productionData, activeFilm, voiceTiming, timeline, knowledge}`
- **设计系统**：`brand.css`（token）、`fm-components.css`（组件约定）、
  `shell/status.ts`（状态唯一来源）—— 见 `design-system.md`
- **导入解析**：VideoLibrary / KnowledgeSources 的真文件解析（`readVideoDuration`）
- **已验收复刻页**：项目指挥中心（callour）、时序校验（dub-editor）
- **壳层模式**：侧栏/顶栏/ProjectBar/复刻页 iframe 装载（`.acr`/`.atr` + 适应层）

## 六、工作流编辑器技术方案

- **推荐 @xyflow/react 12.x（React Flow）**：peer 依赖 `react >= 17`，
  与本仓库 React 19.2 / Vite 8 / Tailwind v4 兼容（已核对 npm 元数据）；
- 交互参考：React Flow AI Workflow 模板 + Dify 执行调试 + Langflow Playground；
- **不引入**未经确认的向量数据库或 LLM 服务；后端未实现时用明确标注的
  mock adapter 展示交互，不得伪装成真实 AI 执行。

## 七、实施阶段与验收
