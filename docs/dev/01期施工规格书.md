## 6. 契约冻结（01期交付）

**交付物**：`docs/contracts/workflow.md`、`docs/contracts/check.md`、`src/types/contracts.ts`（纯类型零实现）。

### 6.1 工作流契约
- `WorkflowDefinition`：`id`、`name`、`version`、`nodes: WorkflowNode[]`（`id`/`type`/`params: Record<string, unknown>`/`inputs`/`outputs`/`meta`）、`edges: { id, from: {node, port}, to: {node, port} }[]`、`createdAt`、`updatedAt`。
- `WorkflowRun`：`runId`、`taskId`、`definitionId`、`definitionVersion`、`status: 'pending'|'running'|'succeeded'|'failed'|'cancelled'`、`nodeIO: Record<nodeId, { inputs, outputs }>`、`error?: { nodeId?, message, code? }`、`startedAt`、`completedAt?`。
- 状态转换：`pending → running → (succeeded | failed | cancelled)`，单向，不回退。

### 6.2 检查契约
- `CheckRun`（P0）：`checkRunId`、`taskId`、`renderId`、`status: 'running'|'completed'|'failed'|'cancelled'`、`startedAt`、`completedAt?`；（P1 预留）`supersedesCheckRunId?`。
- `CheckFinding`（P0）：`findingId`、`checkRunId`、`category`、`severity: 'blocker'|'major'|'minor'|'info'`、`title`、`description`、`targetType: 'scene'|'timeline'|'render'|'asset'|'workflow_node'`、`targetId`、`timecodeMs?`、`evidence?`、`status: 'open'|'doing'|'resolved'|'ignored'`、`suggestedFix?`、`fixAction?`、`createdAt`、`updatedAt`；（P1 预留）`resolvedAt?`、`supersededByFindingId?`。
- **铁律**：用户标记"已处理"（`status='ignored'`/`'resolved'`）≠ 检查通过——"通过"是检查项自身的结论字段，两者在数据与 UI 上分离，不得混用。
- 定位链：`taskId + renderId + checkRunId` 定位运行；`targetType + targetId + timecodeMs` 定位问题；`fixAction` 给修改入口；复检生成新 run 并以 `supersedesCheckRunId` 关联旧 run。

**验收**：两份 md + 一份 ts，三者字段一致；`tsc` 通过；§8 的 01 期退出条件对照打勾。
