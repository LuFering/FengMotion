# 更新日志

本页记录 FengMotion 面向版本的变更：新增、变更、修复、移除与升级注意事项。只记用户可感知的变化与对协作有影响的工程事项；实现细节查 git 历史。

维护规则：

- 顶部保留「未发布」段，随 PR 合入时把变更归入该段；发布时改段名为版本号与日期。
- 同一版本内同一功能的后续修复，直接修订原条目，不重复新增。
- 条目优先写用户影响与操作变化，其次才是实现方式。
- 本日志自 2026-10-22 建立；建立前的历史以「基线」段概括，不逐条追溯。
