# 前后端协议

本协议约定前端与（未来）Agent 后端之间的数据与状态契约。由协作者出前端稿、维护者确认后端可实现性与字段口径后冻结；冻结后的变更走第 6 节流程。

状态：v0.2（2026-10-23 起，字段与端点以 `docs/contracts/` 全量契约 + `src/types/contracts.ts` 为准，本文件只保留总原则与变更流程）。当前后端未接入，契约是双方对齐目标，前端先以演示适配器实现。

## 1. 总原则

- **唯一数据入口**：前端视图只经 `src/services/` 的 studioApi 层取数与执行动作，禁止视图内散落请求与数据拼装。
- **适配器可替换**：演示适配器与真实后端实现同一接口；切换实现不改视图代码。
- **契约先行**：新能力先在本文件补契约（字段、状态、错误），再写实现。
- **诚实标注**：凡经演示适配器返回的数据，UI 必须显式标注 Demo（见第 4 节）；禁止以演示结果冒充真实执行。

## 2. 通用约定

- ID：所有实体使用稳定字符串 ID；跨实体引用只用 ID，不嵌套整对象。
- 时间：统一毫秒时间戳（`startedAt` 等）或 ISO 8601 字符串，同一契约内不混用；时长用毫秒（`timecodeMs`、时长字段）并在字段名注明单位。
- 状态枚举：小写蛇形（`not_run`、`running`、`completed`、`failed`、`cancelled` …），枚举值只增不改义；废弃值保留并标注，不复用。
- 可空性：字段缺失用「不返回该字段」表达，不用空字符串或 0 冒充；未知状态必须有明确的未执行/无数据表达，不得默认成成功。

## 3. 核心对象（前端所需口径）

- **Project / Task**：项目与创作任务。任务状态是全站执行状态的唯一驱动源（工作台顶部摘要、任务页签、我的创作卡片状态都读同一状态，不各存一份）。
- **Artifact（产物）**：版本化产物（渲染结果、关键帧、方案等），带版本号与来源任务；产物浏览器当前为只读演示。
- **AgentReference**：Agent 对场景/帧/时间范围/区域/产物的结构化引用，分 target 与 context 两种角色（已在 studioApi 落地）。

## 4. Demo 标注规范

- 演示适配器返回的数据对象须带可识别的 demo 标记（现有 fixture 约定 `demo: true`）。
- UI 呈现：演示数据在页面上有可见的「演示」标识；由演示数据驱动的操作（恢复、检查通过等）必须禁用或明确标注为演示行为。
- 汇报与文档同样适用：演示链路跑通只能表述为「交互连通」，不得表述为「真实能力完成」。

## 5. 全量 API 契约（`docs/contracts/`）

自 2026-10-23 起，字段、状态、端点、错误码以 `docs/contracts/` 为准，类型唯一来源为 `src/types/contracts.ts`。本文件不再重复字段定义，避免两处口径打架。

| 文档 | 覆盖域 |
|---|---|
| `contracts/README.md` | 通用约定、错误码、分页、并发、SSE、端点总表、跨域状态机 |
| `contracts/project.md` | 项目、时间线、场景、分镜、镜头参数、产物、版本 |
| `contracts/task.md` | 任务请求、任务实体、事件流、变更集 |
| `contracts/workflow.md` | 工作流定义 / 运行 / 模板 |
| `contracts/check.md` | 检查运行、问题项、证据、结论派生 |
| `contracts/render.md` | 渲染、产物、交付、验收 |
| `contracts/asset.md` | 素材、五维状态、文件夹、上传 |
| `contracts/library.md` | 特效库、参考片库、片型画像 |
| `contracts/agent.md` | 对话会话、消息、流式回复 |
| `contracts/settings.md` | 能力、设置、健康检查 |

原「两份待冻结契约」（工作流、检查）与任务协议已并入上表，语义红线不变：**未执行 ≠ 通过**；用户标记「已处理」≠ 复检通过；叙事类结论必须有渲染预览或关键帧证据。

## 6. 契约变更流程

1. 提出方在本文件以 PR 形式修改契约，并写明变更原因与影响面。
2. 另一方确认可实现性（后端）或可呈现性（前端）后合并，视为新版冻结。
3. 已冻结字段不直接改义：需要新语义时新增字段或枚举值，旧值标注废弃并给出迁移期。
4. 实现跟不上契约时，先改演示适配器顶住并保持 Demo 标注，不私自改契约迁就实现。
