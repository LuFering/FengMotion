## 3. AppShell / PageHeader / SearchField / Toolbar（含砍顶栏）

### 3.1 砍顶栏 —— 实际是删死代码，不是砍一个看得见的栏

`.tabbar` 运行时 `display: none`（实测 `getComputedStyle`），里面 5 个标签（首页/工作台/素材/特效/交付）与侧栏 6 项重复且命名不一致。所以这条的实质是**删掉这段渲染了但不可见的重复导航**。

**修改**：
- `src/App.tsx`：删 `TABS` 常量、`<nav className="tabbar">` 整块、相关 import
- `src/styles/workbench.css:342`：`body.flowon .tabbar { flex: 0 0 auto }` 删除
- `src/styles/nav-tree.css` / `paba/app-slim.css` 里 `.tabbar` 规则：paba 侧不动，本项目侧新增的删除

### 3.2 壳与页头

**新建**：`src/shell/AppShell.tsx`、`src/components/PageHeader.tsx`、`src/components/SearchField.tsx`、`src/components/Toolbar.tsx`

**修改**：
- `src/App.tsx`：把「tabbar + sidebar + pane 分发 + app-header」四段收敛到 AppShell；`.app-header` 的 60px 顶栏换成 `PageHeader`
- `src/shell/views.ts`：`NAV_ITEMS`（6 项）与 `VIEW_META` 合并为单一来源（现在 label 在两处各写一遍）
- `src/shell/SidebarNav.tsx`：接新来源
- 受影响的全幅页（`NO_APP_HEADER` 里的 render/project/assets/methods/knowledge/reference）：确认仍不渲染 PageHeader

**验收**：6 个导航页共用一致壳；页面上不再出现第二个全局导航；1440 / 1024 / 768 三档宽度无溢出；全幅页仍全幅。

**做**：统一背景/字体/间距/圆角/按钮与输入框；删 iframe 内重复导航与页头；统一滚动/加载/失败/空态；修返回与当前任务上下文；**示例数据加明确 Demo 标识（必须）**。

**不做**：给 iframe 建组件系统；重写 iframe 内交互细节；在即将原生化的页面上加功能。

**验收**：三页与壳的视觉断层消失；Demo 标识可见；返回/滚动正常。
